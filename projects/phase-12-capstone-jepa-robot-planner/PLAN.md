# 毕业项目计划：PushT 零样本 JEPA 目标规划器（`capstone-jepa-robot-planner`）

> 本文件按 `src/phase-12-capstone/CONCEPT.md` 第 2.4 节「一页计划模板」在正式运行全量实验之前写定，作为预注册协议。

- **问题**：在 PushT 视觉操作任务上，将冻结的预训练视觉编码器（DINOv2 ViT-S/14）替换未预训练的随机卷积补丁编码器，并结合动作条件潜空间预测器与 CEM 规划，能否在零样本目标到达任务上显著提升成功率与表征空间可信视野？
- **假设**：能。预训练 DINOv2 补丁特征已经编码了推杆与物体的空间几何信息（线性探针位置误差显著低于未预训练编码器），因此动作条件预测器只需学习特征如何随动作演化，从而使特征空间 L2 距离与真实空间距离单调相关，支持多步 CEM 规划。
- **方法**：
  - 复用部件：Phase 1 的 `utils.planning.cem_plan`；Phase 10 的离线 DINOv2 ViT-S/14 特征缓存与帧级因果 Transformer 潜空间预测器；Phase 12 的按回合切分、数据集指纹、开环误差与可信视野 $k^\star$、$t$ 区间 / Wilson 区间 / 2×2 相互作用统计工具。
  - 新写部分：统一的双编码器对照（DINOv2 vs 未预训练卷积补丁编码器）、目标条件行为克隆（Goal-Conditioned BC）基线、多种子（$n=5$）实验矩阵与 2×2 预注册消融（规划视野 $H \in \{1, 3\}$ × 代价池化方式 `patch_l2` vs `mean_pool_l2`）。
- **基线**：
  - 简单基线：随机动作策略；目标条件行为克隆（Goal-Conditioned BC，仅在相同演示轨迹上离线监督训练）
  - 对照编码器：未预训练的冻结卷积补丁编码器（Random-PatchCNN + 相同预测器 + CEM）
  - 上界：真实推杆运动学代理 + 同一个 CEM 规划器（Oracle-CEM）
- **主指标**：固定测试起点与可达目标集合上的目标到达成功率（终点推杆距目标 $< 45\,\text{px}$）与平均终点距离；$n = 5$ 个训练种子 × $E = 8$ 个评估任务，报告最后一个检查点的均值 ± 95% $t$ 区间半宽、汇总成功率的 95% Wilson 区间，以及与基线之差的 95% Welch $t$ 区间。
- **世界模型诊断**：表征空间开环预测误差曲线 $e(k)$、相对复制基线比值 $\rho(k) = e(k) / e_{\text{copy}}(k)$、可信视野 $k^\star$（阈值 $c = 0.5$）、以及线性探针读取推杆坐标的 $R^2$ 与像素 RMSE。
- **最小可行实验（MVE）**：`WM_QUICK=1` 模式下使用 2 个种子 × 3 个任务验证整条管线（指纹校验 → 探针 → 预测器训练 → 开环曲线 → CEM 闭环评估 → 原始 JSONL 落盘 → 统计制表与画图）无报错且 DINOv2 探针误差显著低于随机编码器。
- **预算**：本机 CPU 复现离线预计算 DINOv2 特征（一次性缓存约 1–2 分钟），主实验矩阵 6 个格子 × 5 个种子 = 30 次轻量预测器训练与规划评估，预计总耗时 8–15 分钟（0 GPU 费用）。
- **止损条件**：
  - 节点 1（数据与探针）：若 DINOv2 特征上的推杆位置线性探针 $R^2 < 0.70$，检查图像预处理、尺寸缩放与归一化。
  - 节点 2（闭环评估）：若 DINOv2 + JEPA + CEM 成功率未超过目标条件 BC，不隐瞒负结果，改用探针误差与开环视野 $k^\star$ 剖析失败根因并如实写入报告。
- **预注册的消融（2×2 因子设计，在运行实验前定稿）**：
  1. 去掉空间补丁结构（`patch_l2` → `mean_pool_l2`，把 $8\times 8$ 空间补丁平均池化后再算代价）：预期成功率**下降**（幅度中到大），因为空间池化抹平了推杆与目标的二维位置信息。
  2. 缩短规划视野（`horizon=3` → `horizon=1`，贪心单步规划）：预期成功率**下降**（幅度小到中），因为单步视野在目标较远时容易停在局部位置，但若模型多步误差较大也可能分不出来。
  3. 2×2 相互作用（空间补丁代价 × 多步视野）：预期为正或接近可加——只有在保留空间位置的代价函数下，多步前瞻规划的收益才能体现出来。
