## 1. 机器人学习的全景

### 1.1 直觉

前面十章的智能体都活在一个很舒服的世界里：环境是一段程序，`env.step()` 一秒能调几千次，
每一步都返回一个奖励，摔了就 `env.reset()`。这相当于写代码时有一套秒级跑完、想跑多少次跑多少次的单元测试。

真实机器人是另一种开发体验：**没有测试环境，只有生产环境；每跑一次测试要一个人站在旁边花一两分钟；
跑坏了可能要修硬件；而且没有任何断言告诉你这次跑得对不对**，得靠人眼看。

在这种条件下，"让智能体自己试错几百万步"（Phase 4–6 的做法）基本行不通。
这个领域目前的主流做法是另一条路：**让人示范，让机器模仿**。人通过遥操作设备控制机器人把任务做一遍，
相机画面和人给出的动作被录下来，策略网络学的是"看到这样的画面，人会怎么动"。

这条路能走通，但留下三个痛点，本章后面的四种世界模型用法就是冲着它们来的。

### 1.2 定义：机器人模仿学习的标准设定

**数据。** 一份演示数据集由若干条回合（episode）组成，每条回合是一串带时间戳的帧：

$$
\mathcal{D} = \big\lbrace (o_t^{(i)}, a_t^{(i)}, \ell^{(i)}) \big\rbrace, \qquad i = 1 \dots M \text{（回合）}, \quad t = 0 \dots T_i - 1
$$

和前面各章的数据集 $(s, a, r, s')$ 相比，有两处不同：**没有奖励 $r$**，以及多了一条语言指令 $\ell$（多任务时用来说明要做哪件事）。
观测 $o_t$ 通常是一到几路相机图像，加上本体感觉（proprioception）：关节角度、夹爪开合这些机器人自己能读到的量。

**策略。** 策略以最近的观测和指令为输入，输出接下来一小段动作（第 2 节的动作块）：

$$
A_t \sim \pi_\phi(\,\cdot \mid o_{t-T_o+1:t}, \ell)
$$

**评估。** 没有奖励，所以评估指标不是回报，是**成功率**：把策略放到机器人上跑 $n$ 个回合，
由人（或一条写死的规则）判断每个回合成功与否，成功率是成功回合数除以 $n$。

**控制栈。** 策略网络并不直接驱动电机。中间隔着一到两层传统控制器：

```
   ┌───────────────┐  动作块 A_t      ┌───────────────┐  目标位置      ┌───────────────┐
   │   策略网络      │ ──────────────▶ │  插值 / 轨迹生成 │ ────────────▶ │ 底层伺服控制器   │ ──▶ 电机力矩
   │  （神经网络）   │   几 Hz–几十 Hz   │               │  几十–几百 Hz   │（PD / 阻抗控制） │   几百 Hz–1 kHz
   └───────────────┘                 └───────────────┘               └───────────────┘
          ▲                                                                  │
          └────────────── 相机图像（通常 10–60 Hz）+ 关节读数 ◀────────────────┘
```

对读论文来说需要记住的是：论文里说的"动作"几乎都是最左边那一层的输出，
即"接下来希望末端或关节到哪里"，不是力矩。把它变成力矩是底层控制器的事，学习算法通常不碰。
这和 Phase 1 的 `Pendulum-v1` 不同，那里的动作直接就是力矩。

### 1.3 和游戏、仿真控制的三处不同

| | 游戏 / 仿真控制（Phase 1–10） | 真实机器人 |
| --- | --- | --- |
| **数据从哪来** | 智能体自己和环境交互，要多少有多少 | 人类遥操作演示。一条几十秒的演示要一个熟练操作员花同样长的时间，外加摆放物体、复位 |
| **有没有奖励** | 环境每一步都给 | 没有。要么人工标注成功与否，要么另外训练一个成功判别器 |
| **策略怎么学** | 强化学习：试错 + 奖励 | 模仿学习：行为克隆及其变体（ACT、Diffusion Policy、VLA） |
| **怎么评估** | 跑几百个回合取平均，几分钟 | 真机上跑几十个回合，几小时；物体摆放、光照、硬件磨损都影响结果，难复现 |
| **出错的代价** | 重置环境 | 撞坏夹爪、打翻东西、伤到人 |
| **时间** | 仿真时间可以暂停、加速 | 世界不等人：策略还在算，物体已经动了 |

前四行对应 README 里说的三个痛点（数据占两行，然后是策略、评估）。后面两行是真机特有的约束，第 8 节展开。

**数据规模的量级感。** 语言模型用的是整个互联网的文本，视频模型用的是整个互联网的视频。
机器人这边，目前最大的公开跨本体数据集 Open X-Embodiment（arXiv:2310.08864）汇集了
22 种机器人、21 家机构的数据、527 种技能（摘要），轨迹数在百万条量级（论文正文，待核对）。
而要让一个策略在**你自己的**机器人、**你自己的**任务上工作，通常还得再采几十到几百条专门的演示。
"数据少"是这个领域几乎所有设计选择背后的第一约束，也是世界模型（能利用无动作标签的视频）被寄予希望的原因。

### 1.4 策略这一侧的演进

本章的主角是世界模型，但四种用法都是围绕"策略"展开的，所以先把策略这一侧的名字认全。

| 一类方法 | 代表 | 一句话 | 本章哪里讲 |
| --- | --- | --- | --- |
| 行为克隆（BC） | 经典方法 | 把"观测 → 动作"当监督学习 | 第 3 节 |
| 动作分块 | ACT（Zhao et al. 2023，arXiv:2304.13705） | 一次预测一段动作，减少决策次数 | 第 2 节 |
| 扩散策略 | Diffusion Policy（Chi et al. 2023，arXiv:2303.04137） | 用扩散模型生成动作块，能表达多峰分布 | 第 3 节 |
| 视觉-语言-动作模型（VLA） | RT-2（arXiv:2307.15818）、OpenVLA（arXiv:2406.09246）、π0（arXiv:2410.24164） | 拿预训练的视觉语言模型当骨干，输出动作 | 第 1.4 节（仅背景） |
| 通用机器人策略 | Octo（arXiv:2405.12213）、GR00T N1（arXiv:2503.14734） | 在跨本体数据上预训练，再到具体机器人上微调 | 第 1.4 节（仅背景） |

VLA（Vision-Language-Action model）这条线值得多说两句，因为它是世界模型路线的主要对照：

- **RT-1**（Brohan et al. 2022，arXiv:2212.06817）：一个专门为机器人设计的 Transformer，把动作的每一维离散成若干个桶，当分类问题来学。
- **RT-2**（Brohan et al. 2023，arXiv:2307.15818）：直接拿一个视觉语言模型，把动作写成文本 token 让它输出。
  VLA 这个词就是这篇论文提出的。
- **OpenVLA**（Kim et al. 2024，arXiv:2406.09246）：开源的 VLA，在 Open X-Embodiment 的数据上训练。
- **π0**（Black et al. 2024，arXiv:2410.24164）：视觉语言模型骨干 + 一个用 flow matching（Phase 9）生成连续动作块的"动作专家"。
- **GR00T N1**（NVIDIA 2025，arXiv:2503.14734）：面向人形机器人的双系统结构，慢的视觉语言模块负责理解，快的扩散模块负责出动作。

VLA 和世界模型两条路线的分歧，可以用一句话概括：
**VLA 的预训练知识来自"图文对"（知道画面里是什么），世界模型的预训练知识来自"视频"（知道画面接下来会怎么变）。**
前者擅长语义泛化（没见过的物体、没见过的指令），后者的卖点是物理和运动的先验。
2025 年起两条线明显在合流，第 5 节的 World-Action Model 就是合流的产物。

### 1.5 世界模型的四种用法：一张地图

这是本章最重要的一张表。后面第 4–8 节每一节展开其中一行。

| 用法 | 世界模型的输入 → 输出 | 解决哪个痛点 | 代表工作 | 优势 | 主要失败模式 |
| --- | --- | --- | --- | --- | --- |
| **当策略** | 当前画面 + 指令 → 未来画面（再由逆动力学或动作头得到动作） | 策略不会往前看；动作数据少而视频多 | UniPi（arXiv:2302.00111）、GR-1 / GR-2、VPP、UVA、UWM | 能用无动作标签的视频预训练；预测未来提供稠密的监督信号 | 生成的画面物理上不可行；逆动力学解不出动作；推理慢 |
| **当仿真器** | 当前画面 + 策略给出的动作 → 下一画面，闭环滚动 | 评估只能上真机 | IRASim（arXiv:2406.14540）、WorldGym（arXiv:2506.00613）、WorldEval（arXiv:2505.19017） | 不占真机；可并行；可复现 | 长时程漂移；对失败情形预测不准（"幻觉成功"）；成功判定本身不可靠 |
| **当数据引擎** | 起始画面 + 指令 → 新的轨迹视频（再用逆动力学或隐动作打标签） | 数据不够 | DreamGen（arXiv:2505.12705）；Cosmos（arXiv:2501.03575）一类视频基础模型 | 一份演示变多份；能合成没采过的场景和行为 | 生成的轨迹不符合物理；伪动作标签有噪声；策略学到模型的毛病 |
| **真机在线学习** | 真机回放数据 → 隐空间想象轨迹 → 训练 actor-critic；或不训练策略，直接在真机上用模型规划 | 真机交互太贵 | DayDreamer（arXiv:2206.14176）；V-JEPA 2-AC（arXiv:2506.09985，模型是离线训练的，放在这一行是因为它同样直接在真机上用世界模型做决策） | 样本效率高；模型可跨任务复用 | 需要奖励或目标图像；延迟与安全；早期模型不准时的危险动作 |

把这张表和 Phase 1 第 1.4 节的"三种用途"对一下：

```
   Phase 1 的三种用途                本章的四种用法
   ─────────────────                ─────────────────────────────────────────
   预测  ───────────────────────▶   当策略（预测未来画面本身就是计划）
   想象  ───────────────────────▶   当数据引擎（给模仿学习造数据）
                                    真机在线学习之 DayDreamer（给强化学习造数据）
   规划  ───────────────────────▶   真机在线学习之 V-JEPA 2-AC（决策时规划）
   （新）                           当仿真器（不产出动作，只给策略打分）
```

"当仿真器"是唯一一种不直接参与产生动作的用法：它的输出是一个评估结论，消费者是做研究的人。
正因为如此，它需要一套单独的方法学来回答"这个结论可不可信"，这是第 6 节的内容。

### 1.6 机器人数据与部署的现实约束

| 约束 | 具体是什么 | 对方法设计的影响 | 本章哪里展开 |
| --- | --- | --- | --- |
| **数据少** | 演示靠人采，一个任务几十到几百条 | 必须借助预训练（图文、视频）；数据增强；用世界模型造数据 | 第 4、5、7 节 |
| **具身差异**（embodiment gap） | 不同机器人的自由度、相机位置、动作空间都不同；人的手和机器人的夹爪更不同 | 动作表示难以统一；人类视频不能直接当演示用；隐动作是一种绕开办法 | 第 2、4 节 |
| **控制频率** | 策略要以固定频率给出动作，典型值是每秒几次到几十次 | 大模型推理跟不上，需要动作分块、异步执行 | 第 2、8 节 |
| **延迟** | 从相机曝光到电机响应，中间有采集、推理、通信的时间 | 策略看到的是"过去"的世界；动作块里最前面几步可能已经过期 | 第 8 节 |
| **安全** | 机器人会撞、会夹、会摔 | 探索受限；需要动作限幅、力限、急停；世界模型当仿真器的动机之一 | 第 8 节 |
| **评估贵且有噪声** | 每次评估占用真机和人；回合数少，统计误差大 | 需要替代的评估手段，也需要老实报告置信区间 | 第 1.7、6 节 |

### 1.7 推导：几十个回合的成功率有多大的误差

评估是本章反复出现的主题，先把最基本的一件事算清楚：在真机上跑 $n$ 个回合得到的成功率，本身有多不准。

设策略的真实成功率是 $y$。每个回合成功与否是一次独立的伯努利试验，成功记 1，失败记 0。
跑 $n$ 个回合，成功的回合数 $X$ 服从二项分布，测得的成功率是 $X / n$。

**第一步：单次试验的方差。** 伯努利变量 $x \in \lbrace 0, 1 \rbrace$，$\mathbb{E}[x] = y$，又因为 $x^2 = x$，所以

$$
\mathrm{Var}[x] = \mathbb{E}[x^2] - \mathbb{E}[x]^2 = y - y^2 = y(1 - y)
$$

**第二步：$n$ 次独立试验的平均值的方差。** 独立变量之和的方差等于方差之和，再用 $\mathrm{Var}[cX] = c^2\,\mathrm{Var}[X]$：

$$
\mathrm{Var}\Big[\frac{X}{n}\Big] = \frac{1}{n^2} \cdot n \cdot y(1 - y) = \frac{y(1 - y)}{n}
$$

**第三步：开方得到标准误差（standard error）。**

$$
\mathrm{SE} = \sqrt{\frac{y(1 - y)}{n}}
$$

用正态近似，95% 置信区间大约是测得的成功率加减 $1.96\,\mathrm{SE}$。

**手算例子。** 真实成功率 $y = 0.5$（方差最大的情形）：

| 回合数 $n$ | 标准误差 | 95% 区间的半宽 $1.96\,\mathrm{SE}$ |
| --- | --- | --- |
| 10 | $\sqrt{0.25 / 10} = 0.158$ | 0.31 |
| 20 | $\sqrt{0.25 / 20} = 0.112$ | 0.22 |
| 50 | $\sqrt{0.25 / 50} = 0.071$ | 0.14 |
| 100 | $\sqrt{0.25 / 100} = 0.050$ | 0.10 |

真机论文里常见的"每个策略跑 20 个回合"，对应的 95% 区间是正负 22 个百分点。
也就是说，一个策略测出 60%、另一个测出 45%，这 15 个点的差距落在噪声范围之内，不能下结论说前者更好。
要把半宽压到 5 个点，需要 $n = 0.25 \times (1.96 / 0.05)^2 \approx 384$ 个回合，真机上几乎没人跑得起。

这件事有两个推论，后面都会用到：

1. 第 6 节拿"真实成功率"当标准答案去检验世界模型，但这个标准答案自己就带着不小的误差。
2. 样本量小的时候正态近似不准（成功率接近 0 或 1 时尤其如此），应该用 Wilson 区间或自助法。
   评估协议的系统讲法在 Phase 12。

### 1.9 常见误区

- **误区：机器人学习的主流是强化学习。**
  实际情况：操作（manipulation）方向目前的主流是模仿学习。强化学习在足式运动（仿真里训练再迁移到真机）
  和真机微调里用得多。世界模型在两边都有位置：给模仿学习当数据引擎和评估器，给强化学习当想象环境。
- **误区：论文里的动作就是电机力矩。**
  实际情况：绝大多数操作策略输出的是目标位姿或目标关节角，由底层控制器去跟踪。
  这也是为什么动作里会出现"绝对量还是增量"这种选择（第 2 节）。
- **误区：成功率 60% 的策略比 50% 的好。**
  实际情况：要看跑了多少个回合。20 个回合时，这个差距远在噪声之内。
  读真机论文时先找评估回合数，再看成功率。
- **误区：四种用法是四类不同的模型。**
  实际情况：是同一类模型的四种用途。同一个动作条件的视频模型，
  接上逆动力学可以当策略，闭环喂动作可以当仿真器，批量采样可以当数据引擎。
  不少工作（比如 UVA、UWM、Genie Envisioner）一个模型同时演示其中几种。

## 2. 机器人数据与动作分块

### 2.1 直觉

**数据。** 一份机器人演示数据集，本质上是一张带时间戳的日志表：每一行是某个回合的某一帧，
列里放着这一帧的图像、关节读数和人当时给出的动作。和后端的事件日志没有两样，
只是其中一列是图片（实际存成视频文件），而且行与行之间有严格的时间顺序。

**动作分块。** 策略如果每个控制周期只输出一个动作，就像一个视频播放器每播一帧就向服务器请求下一帧：
网络稍微一卡画面就停，而且每次请求都可能拿到和上一帧不连贯的内容。
实际的播放器会**一次缓冲一段**再连续播放。动作分块（action chunking）是同一个想法：
策略一次预测接下来 $k$ 步的动作，机器人连续执行其中的一段，执行期间策略去算下一段。

这个改动看起来只是工程优化，实际上同时解决了三个问题：大模型推理慢、
行为克隆的决策次数太多导致误差累积（第 3 节）、人类演示里有停顿和犹豫这类单帧解释不了的行为。

### 2.2 定义：数据格式

本章用 LeRobot 的数据格式，它是目前开源社区里用得最广的一种。一份数据集在磁盘上分三块：

```
   dataset/
   ├── meta/      元数据：帧率、每一列的名字 / 形状 / 类型、每列的统计量（均值、标准差、最小、最大）、
   │              每个回合的起止位置、任务的语言描述
   ├── data/      低维数据的表（Parquet）：每行一帧
   └── videos/    每路相机一组视频文件（MP4），按帧号和表对齐
```

表里的列（以 PushT 为例）：

| 列 | 形状 | 含义 |
| --- | --- | --- |
| `observation.image` | `[C, H, W]` | 相机画面（从视频文件解码） |
| `observation.state` | `[D_s]` | 本体感觉。PushT 里是推杆的二维位置 |
| `action` | `[D_a]` | 这一帧人给出的动作。PushT 里是推杆的目标位置（二维，绝对坐标） |
| `episode_index`，`frame_index` | 标量 | 属于哪个回合、回合内第几帧 |
| `timestamp` | 标量 | 回合内的时间（秒） |
| `next.reward`，`next.done`，`next.success` | 标量 | 仿真数据才有；真机演示通常没有奖励 |

列名和目录布局在 LeRobot 的几个数据格式版本之间有过调整（待核对，以写讲义时安装的版本为准）。

> 📌 待回填：`lerobot/pusht` 数据集的回合数、总帧数、帧率、图像分辨率，以及 `action` 各维的取值范围，来自 `02-lerobot-data-and-action-chunks.py` 的打印输出。

训练时要的不是单帧，而是"以第 $t$ 帧为锚点的一个时间窗"：往回取 $T_o$ 帧观测，往后取 $k$ 步动作。
LeRobot 用相对时间戳来描述这个窗口（例如观测取 $-0.1$ 秒和 $0$ 秒两帧，动作取 $0$ 到 $1.5$ 秒共 16 帧）。
窗口越过回合边界时，用边界帧填充，并返回一个掩码标出哪些位置是填充的。

### 2.3 定义：动作表示

"动作"这一列里到底放什么，没有统一标准。读论文和复用数据时要先弄清三件事。

**第一，在哪个空间。**

| 空间 | 动作是什么 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 关节空间（joint space） | 每个关节的目标角度 | 无歧义，直接可执行；适合双臂、灵巧手 | 和具体机器人绑定，换一台自由度不同的机器人就对不上 |
| 末端执行器空间（end-effector space） | 夹爪在空间里的目标位姿：位置 3 维 + 姿态 3 维（或更多） | 和任务直接相关（"往前伸 2 厘米"），跨机器人更容易对齐 | 需要逆运动学把位姿换算成关节角；冗余自由度的机械臂有多组解 |

**第二，绝对量还是增量。**

| 形式 | 含义 | 特点 |
| --- | --- | --- |
| 绝对（absolute） | "到这个位姿去" | 误差不累积；但数值范围大，对相机和基座的标定敏感 |
| 增量（delta） | "在当前位姿的基础上移动这么多" | 数值小而集中，好学（和 Phase 1 第 4.3 节预测变化量是同一个道理）；但每步的小误差会累积成位置漂移 |

增量动作配上动作分块时还有一个细节：一个块里的 $k$ 个增量是相对于**块开始时**的位姿，
还是每一步相对于**上一步**的位姿。两种约定都有人用，混了就会出现"机器人越走越偏"的现象。

**第三，夹爪和姿态怎么编码。** 夹爪通常是 1 维（开合程度，或者二值的开 / 合）。
姿态的表示有欧拉角、四元数、轴角、6 维连续表示几种。欧拉角在 $\pm\pi$ 处有跳变，
和 Phase 1 第 4.5 节摆的角度是同一个问题；四元数有 $q$ 和 $-q$ 表示同一姿态的二义性。

几个常见配置：

| 平台 / 数据 | 动作维度 | 内容 |
| --- | --- | --- |
| PushT（本章） | 2 | 推杆的目标位置，绝对坐标 |
| 单臂 + 平行夹爪（常见的 7 维动作） | 7 | 末端位置增量 3 + 姿态增量 3 + 夹爪 1 |
| ALOHA 双臂（ACT 论文） | 14 | 两条 6 自由度机械臂的关节目标角度 + 两个夹爪 |

**归一化。** 和 Phase 1 第 4.4 节一样，动作各维的量纲不同（米、弧度、0–1 的夹爪开合），
训练前要用数据集的统计量归一化，推理后反归一化。统计量存在 `meta/` 里，是模型的一部分。
跨数据集训练时，每个数据集（每种机器人）用自己的统计量。

**具身差异在这里的体现。** 两台机器人的动作向量即使维度相同，同一个数值代表的物理运动也可能不同
（坐标系朝向不同、增量的参考系不同、控制频率不同导致"一步"的时间长度不同）。
这就是为什么跨本体的预训练模型在新机器人上总要微调：它得重新学一遍"我的数字对应这台机器的什么运动"。
第 4.7 节的隐动作是绕开这个问题的一种尝试：不用任何机器人的动作向量，直接从画面变化里学一套通用的"动作"。

### 2.4 定义：动作分块

从第 $t$ 步开始、长度为 $k$ 的动作块是

$$
A_t = (a_t, a_{t+1}, \dots, a_{t+k-1})
$$

策略一次输出整个块：$\hat{A}_t = \pi_\phi(o_{t-T_o+1:t})$。执行时有三个长度要分清（记号来自 Diffusion Policy）：

```
   时间 ─────────────────────────────────────────────────────────────▶

   观测窗口 T_o = 2          预测长度 T_p = 16
   ┌───┬───┐               ┌───┬───┬───┬───┬───┬───┬───┬───┬───┬─ ··· ─┬───┐
   │o_t-1│o_t│  ── 策略 ──▶ │ â │ â │ â │ â │ â │ â │ â │ â │ â │       │ â │
   └───┴───┘               └───┴───┴───┴───┴───┴───┴───┴───┴───┴─ ··· ─┴───┘
                           └────── 实际执行 T_a = 8 ──────┘└──── 丢弃 ────┘
                                                          │
                                           在这里拿新的观测，重新预测下一个块
```

| 长度 | 含义 | 论文里的典型取值 |
| --- | --- | --- |
| $T_o$ | 输入多少帧历史观测 | Diffusion Policy 常用 2 |
| $T_p$（即 $k$） | 一次预测多少步动作 | Diffusion Policy 常用 16；ACT 在 ALOHA 上用 100（控制频率 50 Hz，相当于 2 秒） |
| $T_a$ | 实际执行多少步后重新预测 | Diffusion Policy 常用 8；ACT 配合时间集成时每步都重新预测 |

这些取值出自两篇论文的实验设置部分，不同任务有出入（待核对）。

这和 Phase 1 第 6.4 节的滚动时域是同一个结构：规划一段、执行前面一部分、重新规划。
区别在于那里的"规划"是在模型里搜索，这里是策略网络的一次前向计算；
那里只执行 1 步，这里执行 $T_a$ 步。$T_a$ 就是 Phase 1 第 13 节 Q7 里说的"多执行几个动作"。

### 2.5 推导：为什么分块有用，代价是什么

**账一：决策次数。** 一个回合有 $T$ 个控制步。每个块执行 $T_a$ 步，策略一共要做的决策次数是

$$
T_{\text{dec}} = \Big\lceil \frac{T}{T_a} \Big\rceil
$$

第 3.4 节会推出：行为克隆的误差累积主要取决于决策次数，而不是物理时间有多长。
假设每次决策独立地以概率 $\epsilon$ 出错，整个回合一次都不出错的概率是 $(1 - \epsilon)^{T_{\text{dec}}}$。

**手算例子。** 回合长 $T = 100$ 步，$\epsilon = 0.01$：

| 做法 | 决策次数 | 一次都不出错的概率 |
| --- | --- | --- |
| 每步决策（$T_a = 1$） | 100 | $0.99^{100} = 0.366$ |
| 每 10 步决策（$T_a = 10$） | 10 | $0.99^{10} = 0.904$ |

这是一个示意性的计算，它假设"预测一整块"和"预测一步"的出错概率相同。
实际上预测得越远越难，$\epsilon$ 会随块长度增大。分块是在"决策次数少"和"每次决策更难"之间取折中。

**账二：反应时间。** 执行一个块期间，策略不看新的观测，这段时间是开环的。最长的"盲区"是

$$
t_{\text{blind}} = T_a \cdot \Delta t
$$

10 Hz 控制、$T_a = 8$ 时是 0.8 秒；50 Hz 控制、$T_a = 100$ 时是 2 秒。
如果这段时间里物体被碰了一下、或者上一个块预测得不准，机器人要等到块执行完才有机会纠正。
这和 Phase 1 第 6.4 节的结论一致：重新规划的间隔越长，对意外的反应越慢。

**账三：推理预算。** 分块让"推理时间必须小于一个控制周期"这个约束放宽了 $T_a$ 倍。
同步执行（算完再动）时，只要求

$$
\delta_{\text{inf}} \le T_a \cdot \Delta t
$$

例如 10 Hz 控制、$T_a = 8$：推理可以用到 0.8 秒，而不是 0.1 秒。
这是扩散策略（要跑多步去噪）和 VLA（几十亿参数）能上真机的前提。延迟带来的其他问题见第 8.3 节。

**时间集成（temporal ensembling）。** ACT 提出的另一种执行方式：每一步都预测一个完整的块，
于是对当前时刻 $t$ 要执行的动作，手上有好几个预测，分别来自 $t$、$t-1$、$t-2$ …… 时刻预测的块。
把它们加权平均：

$$
a_t = \frac{\sum_{i} w_i \, \hat{a}_t^{(i)}}{\sum_{i} w_i}, \qquad w_i = \exp(-m \cdot i)
$$

其中 $\hat{a}_t^{(i)}$ 按预测时间从早到晚排列，$i = 0$ 是**最早**做出的那个预测（ACT 论文的约定），
$m$ 控制新预测融入的速度：$m$ 越小，各预测的权重越接近，新预测占的份额越大，融入得越快；
$m$ 越大，权重越集中在最早的预测上，动作越"固执"。

**手算例子。** 对当前要执行的动作，有三个预测：两步前预测的 0.50、一步前预测的 0.56、刚预测的 0.62。取 $m = 0.5$：

| 预测 | 值 | $i$ | 权重 $e^{-0.5 i}$ |
| --- | --- | --- | --- |
| 两步前 | 0.50 | 0 | 1.000 |
| 一步前 | 0.56 | 1 | 0.607 |
| 当前 | 0.62 | 2 | 0.368 |

$$
a_t = \frac{1.000 \times 0.50 + 0.607 \times 0.56 + 0.368 \times 0.62}{1.000 + 0.607 + 0.368} = \frac{0.500 + 0.340 + 0.228}{1.975} = 0.541
$$

结果（0.541）落在三个预测之间，偏向较早的两个。如果每一步都直接执行最新的预测（0.62），
相邻两步的动作来自两次不同的推理，容易抖；加权平均相当于给动作序列做了一次低通滤波。
代价是每一步都要推理一次，账三的好处没有了。

**分块为什么还能缓解"演示里的停顿"。** 人在遥操作时会犹豫、会停一下再继续。
停顿期间画面不变，但人接下来做什么取决于他"已经停了多久"，单帧观测里没有这个信息，
这违反了马尔可夫性（Phase 1 第 3.3 节）。逐步预测的策略在这种帧上学到的是"停着不动"和"开始动"的平均，
部署时可能永远停在那里。一次预测一整块时，"停几步然后动"被作为一个整体学进去，这个问题就轻得多（ACT 论文的论点）。

### 2.8 常见误区

- **误区：动作分块只是为了省推理时间。**
  实际情况：它还减少了决策次数（减轻误差累积），并且把演示里的停顿、连贯的子动作作为整体来学。
  ACT 论文引入分块的首要理由是后两条。
- **误区：块越长越好。**
  实际情况：块越长，开环的盲区越长，块尾部的预测也越不准。
  常见做法是预测得长一些（$T_p$ 大），但只执行前面一部分（$T_a < T_p$）。
- **误区：不同数据集的动作可以直接拼在一起训练。**
  实际情况：空间（关节 / 末端）、形式（绝对 / 增量）、参考系、频率、归一化统计量都可能不同。
  拼之前要逐项对齐，对不齐的维度要么分开用不同的输出头，要么丢掉。
- **误区：增量动作不会漂移，因为每步都很小。**
  实际情况：每步的小误差加起来就是位置漂移，和 Phase 1 的复合误差同理。
  闭环策略能靠新的观测纠正；开环执行一个长的增量动作块就纠正不了。

## 3. 行为克隆与 Diffusion Policy

### 3.1 直觉

行为克隆（Behavior Cloning，BC）是最朴素的模仿学习：把演示数据当成一份监督学习数据集，
输入是观测，标签是人当时的动作，训练一个网络去拟合。它不需要奖励，不需要环境，不需要任何强化学习。

它有两个出名的毛病。

**毛病一：一步错，步步错。** 设想只看行车记录仪的录像学开车。录像里的司机一直开在车道中间，
所以你从没见过"车身已经偏出车道一半"时该怎么办。上路之后你难免偏一点，
而偏了之后的画面是你没学过的，于是处理得更差，偏得更多。
这和 Phase 1 第 5.6 节世界模型的分布偏移是同一个机制，Phase 1 在那里已经预告过。

**毛病二：多个正确答案的平均是错误答案。** 前面有个障碍物，演示里一半的人从左边绕，一半从右边绕。
用均方误差训练的网络会输出两者的平均：直直地撞上去。

Diffusion Policy 针对的是毛病二：用扩散模型来表示"给定观测时动作块的分布"，采样时落到其中一个峰上。
动作分块和它配合，缓解毛病一。

### 3.2 定义：行为克隆

行为克隆的目标是让演示里的动作在策略下的似然最大：

$$
\max_\phi \; \mathbb{E}_{(o, a) \sim \mathcal{D}} \big[ \log \pi_\phi(a \mid o) \big]
$$

如果把策略取成方差固定的高斯分布 $\pi_\phi(a \mid o) = \mathcal{N}(a; f_\phi(o), \sigma^2 I)$，
按 Phase 1 第 8.3 节的推导（高斯负对数似然在方差固定时退化成平方误差），目标变成

$$
\min_\phi \; \mathbb{E}_{(o, a) \sim \mathcal{D}} \big[ \Vert a - f_\phi(o) \Vert^2 \big]
$$

这就是最常见的"MSE 行为克隆"。

### 3.3 推导：MSE 的最优解是条件均值

固定一个观测 $o$。数据里这个观测对应的动作有一个分布 $p(a \mid o)$。
网络在这个观测上输出一个值 $f$。问：$f$ 取多少时平方误差的期望最小？

**第一步：写出期望并展开平方。**

$$
\mathbb{E}_{a \sim p(\cdot \mid o)} \big[ (a - f)^2 \big] = \mathbb{E}[a^2] - 2 f \, \mathbb{E}[a] + f^2
$$

**第二步：对 $f$ 求导并令其为零。**

$$
\frac{d}{df} \Big( \mathbb{E}[a^2] - 2 f \, \mathbb{E}[a] + f^2 \Big) = -2\,\mathbb{E}[a] + 2f = 0
\quad \Longrightarrow \quad
f^\star(o) = \mathbb{E}[a \mid o]
$$

**第三步：最小值是条件方差。** 把 $f^\star$ 代回去：

$$
\mathbb{E}\big[(a - \mathbb{E}[a])^2\big] = \mathrm{Var}[a \mid o]
$$

结论：**MSE 训练出来的网络输出的是动作的条件均值，而且永远消不掉的那部分损失等于条件方差。**
这个结论在第 4 节推导逆动力学的回归目标时还要用一次。

**手算例子。** 障碍物在正前方。演示里一半的人向左打方向（$a = -1$），一半向右（$a = +1$）。

$$
f^\star = 0.5 \times (-1) + 0.5 \times (+1) = 0, \qquad \text{最小损失} = 0.5 \times (-1 - 0)^2 + 0.5 \times (1 - 0)^2 = 1
$$

网络学到的是"方向盘不动"，这是数据里一次都没出现过的动作。训练损失停在 1 降不下去，
不是因为网络不够大，而是因为这个损失函数的最优解本来就在两个峰的中间。

这种现象叫**均值塌缩**（mode averaging）。解决它需要一个能表达多峰分布的策略：
混合高斯（Phase 2 的 MDN）、把动作离散化后做分类（RT-1、RT-2）、带隐变量的生成模型（ACT 用条件 VAE）、
或者扩散模型（Diffusion Policy）。

### 3.4 推导：分布偏移与误差的平方增长

现在处理毛病一。设回合长度为 $T$，用下面的简化设定（出自 Ross & Bagnell 2010 的分析思路，这里取最简单的版本）：

- 在**专家会到达的状态**上，学到的策略每一步以概率 $\epsilon$ 做出和专家不同的动作（"出错"）。
- 策略一旦出错，就离开了专家的状态分布。最坏情况下它再也回不来，此后每一步都付出代价 1。
- 没出错的步代价为 0。

**第一步：第一次出错发生在第 $t$ 步的概率。** 前 $t - 1$ 步都没出错（此时状态还在专家分布上），第 $t$ 步出错：

$$
P(\text{第一次出错在第 } t \text{ 步}) = (1 - \epsilon)^{t-1} \epsilon \le \epsilon
$$

**第二步：如果第一次出错在第 $t$ 步，最坏的总代价。** 从第 $t$ 步到第 $T$ 步，每步代价 1：

$$
\text{代价} \le T - t + 1
$$

**第三步：对 $t$ 求和，用等差数列求和公式。**

$$
\mathbb{E}[\text{总代价}] \le \sum_{t=1}^{T} \epsilon \, (T - t + 1) = \epsilon \, (T + (T - 1) + \dots + 1) = \epsilon \, \frac{T(T + 1)}{2}
$$

期望代价的上界随回合长度**平方**增长，记作 $O(\epsilon T^2)$。

对比一下：如果出错之后能立刻回到专家分布（比如有人随时把你扶正），每一步独立地以概率 $\epsilon$ 付出代价 1，
总代价是 $\epsilon T$，线性增长。多出来的那个 $T$，就是"错了之后回不来"的代价。

**手算例子。** $\epsilon = 0.01$：

| 回合长度 $T$ | 线性 $\epsilon T$ | 平方上界 $\epsilon T(T+1)/2$ | 上界占回合长度的比例 |
| --- | --- | --- | --- |
| 10 | 0.1 | 0.55 | 5.5% |
| 50 | 0.5 | 12.75 | 25.5% |
| 100 | 1.0 | 50.5 | 50.5% |

单步只有 1% 的出错概率，100 步的回合里，最坏情况下平均有一半的时间处在"已经出错"的状态。
和第 2.5 节的账一合起来看：把 100 次决策减到 10 次（每次决策管 10 步），同样的 $\epsilon$ 下，
上界从 50.5 步降到 $0.01 \times 10 \times 11 / 2 = 0.55$ 个块，也就是 5.5 步。
前提仍然是"预测一个块"的出错概率没有比"预测一步"高太多。

**和世界模型复合误差的对照。** 这个推导和 Phase 1 第 5.3 节是同一种结构：

| | 世界模型的开环展开（Phase 1） | 行为克隆的闭环执行（本节） |
| --- | --- | --- |
| 谁在犯错 | 模型 $f_\theta$ 预测下一状态 | 策略 $\pi_\phi$ 预测动作 |
| 错误怎么传下去 | 预测的状态成为下一步的输入 | 错误的动作把系统带到新的状态，成为下一步的输入 |
| 训练分布 | 数据集里的 $(s, a)$ | 专家访问的状态 |
| 使用时的分布 | 模型自己展开出来的状态 | 策略自己走出来的状态 |
| 误差增长 | $e_{t+1} \le L\,e_t + \varepsilon$，可达指数 | $O(\epsilon T^2)$ |
| 缓解办法 | 短视野 + 重新规划；迭代采集数据 | 动作分块；DAgger；数据里加入纠错演示 |

两者是同一个病：**训练时的输入来自别人，使用时的输入来自自己。**

### 3.5 DAgger：让专家给"自己走出来的状态"打标签

DAgger（Ross et al. 2011，arXiv:1011.0686）的办法和 Phase 1 第 9 节 PETS 的迭代采集是同一个思路：
既然问题出在策略会走到数据里没有的状态，那就让策略自己去走，把它走到的状态交给专家标注正确动作，
加进数据集再训练。

```
算法：DAgger

 1. 用专家演示训练初始策略 π_1；数据集 D ← 专家演示
 2. 对 i = 1 … N：
        用 π_i（可以按一定比例混入专家的动作）在环境里跑，记录它访问的状态
        请专家给这些状态标注"这时应该做什么动作"
        把（状态，专家动作）加进 D
        在 D 上重新训练，得到 π_{i+1}
```

理论上，DAgger 把误差上界从关于 $T$ 的平方降回线性（论文的主要结论）。

在真机上直接用它很别扭：它要求人对着一段"不是自己操作出来的"画面，说出每一帧该做什么动作。
实际的做法是它的变体：策略自己跑，人在旁边盯着，看到要出错时接管操作，把接管的这一段当作纠错数据加进去。
另一种更省事的办法是在采集演示时故意让操作员从偏离的位置开始、或者中途给系统加一点扰动，
让数据里天然包含"怎么纠正回来"的片段。

### 3.6 Diffusion Policy：用扩散模型生成动作块

**定义。** Diffusion Policy（Chi et al. 2023，arXiv:2303.04137）把策略写成一个条件扩散模型：
生成的对象不是图像，是一个动作块 $A \in \mathbb{R}^{k \times D_a}$；条件是最近的观测 $O_t = o_{t-T_o+1:t}$。

训练和旧课的 DDPM 完全一样，只是被加噪的东西换了。记干净的动作块为 $A^{(0)}$，
第 $j$ 个扩散步的加噪结果为

$$
A^{(j)} = \sqrt{\bar\alpha_j} \, A^{(0)} + \sqrt{1 - \bar\alpha_j} \, \eta, \qquad \eta \sim \mathcal{N}(0, I)
$$

网络 $\eta_\phi$ 以加噪的动作块、扩散步 $j$、观测为输入，预测所加的噪声：

$$
\mathcal{L}_{\text{DP}} = \mathbb{E}_{(O_t, A^{(0)}) \sim \mathcal{D}, \; j, \; \eta} \Big[ \big\Vert \eta - \eta_\phi\big(A^{(j)}, j, O_t\big) \big\Vert^2 \Big]
$$

噪声在旧课和论文里记作 $\epsilon$，本章为了不和第 3.4 节的出错概率混淆写作 $\eta$。
上标 $(j)$ 是扩散步，下标 $t$ 是环境的时间步，两者不要混。

推理时从纯噪声 $A^{(J)} \sim \mathcal{N}(0, I)$ 出发，以观测为条件逐步去噪，得到一个动作块，按第 2.4 节的方式执行其中前 $T_a$ 步。

```
                                 观测 O_t（图像经视觉编码器 + 本体感觉）
                                              │ 条件
                                              ▼
   纯噪声 A^(J) ──▶ 去噪 ──▶ A^(J-1) ──▶ ··· ──▶ 去噪 ──▶ A^(0) = 动作块 [k, D_a]
   [k, D_a]         η_φ                          η_φ          │
                                                              └─▶ 执行前 T_a 步，然后重新来
```

**为什么它不会均值塌缩：手算最优去噪器。** 回到第 3.3 节的例子：干净动作 $a$ 以各一半的概率取 $-1$ 或 $+1$。
加噪后观察到 $x = a + \sigma n$，$n \sim \mathcal{N}(0, 1)$。
为了看得清楚，这里让去噪器直接预测干净的动作（它和预测噪声可以互相换算，见旧课的 DDPM）。
按第 3.3 节的结论，用 MSE 训练的去噪器的最优输出是条件均值 $\mathbb{E}[a \mid x]$。

**第一步：用贝叶斯公式写出后验。** 先验各一半，似然是高斯：

$$
P(a = +1 \mid x) = \frac{\exp\big(-\frac{(x - 1)^2}{2\sigma^2}\big)}{\exp\big(-\frac{(x - 1)^2}{2\sigma^2}\big) + \exp\big(-\frac{(x + 1)^2}{2\sigma^2}\big)}
$$

**第二步：分子分母同除以分母的第二项。** 用 $(x + 1)^2 - (x - 1)^2 = 4x$：

$$
P(a = +1 \mid x) = \frac{e^{2x / \sigma^2}}{e^{2x / \sigma^2} + 1}
$$

**第三步：求条件均值。** $\mathbb{E}[a \mid x] = (+1) \cdot P(+1 \mid x) + (-1) \cdot P(-1 \mid x)$：

$$
\mathbb{E}[a \mid x] = \frac{e^{2x / \sigma^2} - 1}{e^{2x / \sigma^2} + 1} = \tanh\Big(\frac{x}{\sigma^2}\Big)
$$

**代入数字。** 取噪声水平 $\sigma = 0.5$：

| 当前的 $x$ | $x / \sigma^2$ | 最优去噪结果 $\tanh(x / \sigma^2)$ |
| --- | --- | --- |
| 0.3 | 1.2 | 0.834 |
| −0.3 | −1.2 | −0.834 |
| 0 | 0 | 0 |

只要 $x$ 稍微偏向某一侧，去噪器就把它推向那一侧的峰（0.3 被推到 0.834），而不是拉回中间。
$x = 0$ 是一个不稳定的平衡点：采样过程中的随机性会让它偏离，一旦偏离就被推向 $\pm 1$ 之一。
最终样本要么落在 $-1$ 附近，要么落在 $+1$ 附近，各占一半。**扩散模型学的是整个分布的形状，采样时才选峰。**

**论文里几个值得知道的设计**（出自论文的方法与实验部分）：

| 设计 | 内容 |
| --- | --- |
| 预测动作序列而不是单步动作 | 即动作分块；论文称之为 action-sequence prediction，并指出它带来时间上的一致性：同一个块里的动作来自同一次采样，不会前一步选左、后一步选右 |
| 滚动时域执行 | 预测 $T_p$ 步，执行 $T_a$ 步 |
| 观测作为条件而不是联合生成的一部分 | 视觉特征只算一次，在多个去噪步里复用，省计算 |
| 两种去噪网络 | 基于一维时间卷积的 U-Net，和基于 Transformer 的版本 |
| 位置控制优于速度控制 | 论文发现扩散策略配合位置控制的动作空间效果更好 |
| 少步推理 | 训练用较多的扩散步，推理时用 DDIM 等采样器减少步数以满足实时要求（具体步数待核对） |

论文摘要给出的总体结果：在来自 4 个操作基准的多个任务上，相对当时的方法平均提升 46.9%。
PushT 就是这篇论文让它流行起来的任务之一，这也是本课程选它作为贯穿任务的原因。

**和世界模型的关系。** Diffusion Policy 是"在动作空间里做扩散"，Phase 9 的扩散世界模型是"在观测空间里做扩散"。
两者的网络结构、训练目标、采样器几乎可以共用。第 5 节的 World-Action Model 就是把这两个扩散过程放进同一个网络。

### 3.7 算法

```
算法：Diffusion Policy 训练

重复：
 1. 取一个小批量 (O_t, A^(0))                    观测窗口 [B, T_o, …]，动作块 [B, k, D_a]
 2. 采样扩散步 j ~ Uniform{1…J}，噪声 η ~ N(0, I)  形状 [B, k, D_a]
 3. 加噪：A^(j) = sqrt(ᾱ_j) · A^(0) + sqrt(1 − ᾱ_j) · η
 4. 损失 = mean((η − η_φ(A^(j), j, O_t))²)，填充位置不计入
 5. 反向传播，更新 φ（通常同时维护一份参数的 EMA，推理时用 EMA 的参数）
```

```
算法：Diffusion Policy 推理（一次重新规划）

输入：最近 T_o 帧观测 O_t
 1. 编码观测，得到条件向量（只算一次）
 2. A ← N(0, I)                                  形状 [1, k, D_a]
 3. 对少量去噪步 j（从大到小）：
        A ← 采样器一步(A, η_φ(A, j, O_t))
 4. 反归一化 A，执行前 T_a 步
```

### 3.9 常见误区

- **误区：行为克隆效果不好是因为网络不够大或者训练不够久。**
  实际情况：均值塌缩是损失函数的问题，分布偏移是数据分布的问题。两者都不会因为加大网络而消失。
- **误区：Diffusion Policy 解决了分布偏移。**
  实际情况：它解决的是多峰问题。分布偏移仍然存在，靠动作分块、更多样的演示、纠错数据来缓解。
- **误区：扩散策略的随机性是坏事，应该每次取均值。**
  实际情况：对多峰分布取均值正是要避免的事。随机性是选峰的机制。
  需要注意的是相邻两次重新规划可能选了不同的峰，所以 $T_a$ 不能太小，或者要用上一个块的结果来引导下一次采样。
- **误区：验证集上的动作预测误差低，策略的成功率就高。**
  实际情况：和 Phase 1 第 4.9 节"单步验证损失低不代表多步能用"是同一件事。
  验证损失是在专家的状态分布上算的，成功率是在策略自己的状态分布上测的。
  机器人学习里，验证损失和成功率经常对不上，所以才必须做闭环评估，也才有第 6 节。

## 4. 把视频预测当策略

### 4.1 直觉

照着视频学做菜的时候，你做的其实是两件事。第一件是看懂"接下来画面应该变成什么样"：
蛋液倒进锅里，然后被铲子划散。第二件是让自己的手把这个变化做出来。
第一件事可以从任何人的视频里学，和你的手长什么样无关；第二件事只和你自己的身体有关，
而且不难：你早就知道自己的手怎么动会让铲子往哪走。

"把视频预测当策略"就是把策略拆成这两半：

- **视频预测模型**回答"接下来应该看到什么"。它可以在海量的、没有动作标签的视频上预训练。
- **逆动力学模型**（Inverse Dynamics Model，IDM）回答"要让画面从这一帧变到下一帧，我该做什么动作"。
  它只需要这台机器人自己的少量数据。

对工程师来说，这是**声明式**和**命令式**的分工。视频模型给出的是期望状态（像一份 Kubernetes 清单，或者 React 里你声明的 UI），
逆动力学模型是那个负责对账的控制器：比较当前状态和期望状态，算出要执行的操作。
更贴切的类比是 `diff`：给它前后两个快照，它告诉你中间做了什么修改。

这个类比也预告了本节的核心难点：**有些修改从快照里看不出来**。
你把一个文件改了又改回去，`diff` 是空的；机器人对着一堵墙使劲推，前后两帧一模一样。
逆动力学什么时候解得出动作、什么时候解不出，是本节推导要回答的问题。

### 4.2 定义

本节涉及四个条件分布，先并排放在一起：

| 名字 | 记号 | 输入 → 输出 | 回答的问题 |
| --- | --- | --- | --- |
| 前向动力学（世界模型） | $p(o_{t+1} \mid o_t, a_t)$ | 当前观测 + 动作 → 下一观测 | 我这样做，会怎样？ |
| 逆动力学 | $p(a_t \mid o_t, o_{t+1})$ | 当前观测 + 下一观测 → 动作 | 发生了这样的变化，是做了什么？ |
| 策略 | $\pi(a_t \mid o_t)$ | 当前观测 → 动作 | 现在该做什么？ |
| 视频预测（不带动作） | $p(o_{t+1} \mid o_t)$ | 当前观测 → 下一观测 | 接下来会看到什么？ |

为了记号简洁，本节先写单步、省略语言指令 $\ell$ 和更早的历史；它们只是额外的条件，不影响推导。

**逆动力学模型**是一个参数为 $\xi$ 的网络 $q_\xi(a_t \mid o_t, o_{t+1})$，用带动作标签的转移数据训练。

**视频预测策略**把两个学到的模型串起来。给定当前观测和指令，先让视频模型采样一个"下一帧"，
再让逆动力学模型从（当前帧，采样的下一帧）里解出动作：

$$
\hat{o}_{t+1} \sim p_\theta(o_{t+1} \mid o_t, \ell), \qquad a_t \sim q_\xi(a_t \mid o_t, \hat{o}_{t+1})
$$

写成一个式子，这个组合出来的策略是

$$
\pi_{\theta, \xi}(a_t \mid o_t, \ell) = \int q_\xi(a_t \mid o_t, o_{t+1}) \; p_\theta(o_{t+1} \mid o_t, \ell) \; do_{t+1}
$$

```
                    ┌──────────────────────┐
   当前画面 o_t ───▶ │ 视频预测模型 p_θ       │ ──▶ 预测的未来画面 ô_{t+1}, ô_{t+2}, …, ô_{t+H}
   语言指令 ℓ  ───▶ │（可用无动作标签的视频   │              │
                    │  预训练）              │              │ 相邻两帧一组
                    └──────────────────────┘              ▼
                                                ┌──────────────────────┐
                                                │ 逆动力学模型 q_ξ       │ ──▶ 动作 a_t, a_{t+1}, …
                                                │（只需本机器人的少量     │
                                                │  带动作数据）          │
                                                └──────────────────────┘
```

### 4.3 推导（一）：逆动力学的训练目标

**最大似然目标。** 数据集里的每一条转移 $(o_t, a_t, o_{t+1})$ 都是一个带标签的样本：
输入是前后两帧，标签是中间的动作。让标签在模型下的似然最大：

$$
\max_\xi \; \mathbb{E}_{(o_t, a_t, o_{t+1}) \sim \mathcal{D}} \big[ \log q_\xi(a_t \mid o_t, o_{t+1}) \big]
$$

**连续动作：回归目标。** 取 $q_\xi(a \mid o, o') = \mathcal{N}(a; g_\xi(o, o'), \sigma^2 I)$，方差固定。
和第 3.2 节同样的一步（高斯负对数似然在方差固定时退化成平方误差），得到

$$
\mathcal{L}_{\text{IDM}}(\xi) = \mathbb{E}_{(o_t, a_t, o_{t+1}) \sim \mathcal{D}} \Big[ \big\Vert a_t - g_\xi(o_t, o_{t+1}) \big\Vert^2 \Big]
$$

**离散动作：分类目标。** 动作是有限个类别时，$q_\xi$ 输出每个类别的概率，目标就是交叉熵：

$$
\mathcal{L}_{\text{IDM}}(\xi) = -\,\mathbb{E}_{(o_t, a_t, o_{t+1}) \sim \mathcal{D}} \big[ \log q_\xi(a_t \mid o_t, o_{t+1}) \big]
$$

**最优解是什么。** 直接套用第 3.3 节的结论，只是条件从 $o$ 换成了 $(o, o')$：
回归目标的最优解是条件均值 $g^\star(o, o') = \mathbb{E}[a \mid o, o']$，
消不掉的损失是条件方差 $\mathrm{Var}[a \mid o, o']$；分类目标的最优解是数据里的条件分布本身。

所以关键问题变成：**数据里的 $p(a \mid o, o')$ 到底是一个什么分布？**

### 4.4 推导（二）：逆动力学与前向动力学的关系

数据集里的转移是这样产生的：某个状态下看到观测 $o_t$；采集数据的策略 $\pi_\beta$ 选了动作 $a_t$；
环境按真实的前向动力学给出 $o_{t+1}$。把观测的分布记作 $d_\beta(o)$。

**第一步：写出三元组的联合分布。** 用概率的链式法则，按"产生的先后顺序"分解：

$$
p_\beta(o_t, a_t, o_{t+1}) = d_\beta(o_t) \; \pi_\beta(a_t \mid o_t) \; p(o_{t+1} \mid o_t, a_t)
$$

三个因子里只有最后一个是环境的属性，前两个都取决于数据是谁采的。

**第二步：用条件概率的定义写出逆动力学。**

$$
p_\beta(a_t \mid o_t, o_{t+1}) = \frac{p_\beta(o_t, a_t, o_{t+1})}{p_\beta(o_t, o_{t+1})}
$$

**第三步：分母是把分子对动作求和（边缘化）。**

$$
p_\beta(o_t, o_{t+1}) = \sum_{a'} p_\beta(o_t, a', o_{t+1}) = d_\beta(o_t) \sum_{a'} \pi_\beta(a' \mid o_t) \; p(o_{t+1} \mid o_t, a')
$$

连续动作时把求和换成积分。

**第四步：代入第一步的分解，分子分母的 $d_\beta(o_t)$ 约掉。**

$$
p_\beta(a_t \mid o_t, o_{t+1}) = \frac{p(o_{t+1} \mid o_t, a_t) \; \pi_\beta(a_t \mid o_t)}{\sum_{a'} p(o_{t+1} \mid o_t, a') \; \pi_\beta(a' \mid o_t)}
$$

分母与 $a_t$ 无关，所以

$$
\underbrace{p_\beta(a_t \mid o_t, o_{t+1})}_{\text{逆动力学（后验）}} \;\propto\; \underbrace{p(o_{t+1} \mid o_t, a_t)}_{\text{前向动力学（似然）}} \;\cdot\; \underbrace{\pi_\beta(a_t \mid o_t)}_{\text{采集策略（先验）}}
$$

这就是贝叶斯公式。它说了三件事。

**结论一：逆动力学不是环境的固有属性。** 前向动力学 $p(o' \mid o, a)$ 只和物理有关，谁来采数据都一样。
逆动力学的式子里多了一个 $\pi_\beta$：同一个环境，换一个人采数据，"正确的"逆动力学就变了。
这也是记号里特意带上下标 $\beta$ 的原因。

**结论二：什么时候这个依赖会消失。** 如果环境是确定性的，而且在观测 $o$ 处不同的动作必然导致不同的下一观测
（映射 $a \mapsto o'$ 是单射），那么对一个给定的 $o'$，似然 $p(o' \mid o, a)$ 只在唯一的一个动作上不为零。
分子里只剩这一项，分母里也只剩这一项，$\pi_\beta$ 被约掉：

$$
p_\beta(a \mid o, o') = \frac{1 \cdot \pi_\beta(a^\star \mid o)}{1 \cdot \pi_\beta(a^\star \mid o)} = 1 \quad (a = a^\star), \qquad \text{其余为 } 0
$$

前提是 $\pi_\beta(a^\star \mid o) > 0$，即采集策略在这个状态下做过这个动作。
这时逆动力学是一个定义良好的函数，和谁采的数据无关，**动作是可辨识的**（identifiable）。
"似然足够尖锐"是逆动力学好用的根本原因，"数据覆盖到"是它的前提。

**结论三：什么时候动作不可辨识。** 只要似然在几个动作上都不为零，后验就要靠先验来分配，
逆动力学学到的是采集策略的习惯，而不是物理上的必然。常见的情形：

| 情形 | 例子 | 似然出了什么问题 |
| --- | --- | --- |
| 不同动作导致相同的结果 | 顶着墙推；夹爪已经夹紧后继续加力；动作超出限幅被截断 | 几个动作的似然完全相同 |
| 动作的效果不在观测里 | 机械臂被物体挡住；冗余自由度的内部运动相机看不出来；指尖的力 | 观测丢了信息，等效于几个动作的似然相同 |
| 环境有随机性 | 打滑、物体滚动、传感器噪声 | 似然是一个宽的分布，许多动作都有可能 |
| 动作的效果有延迟 | 指令发出后几帧机械臂才动 | 相邻两帧的差别反映的是更早的动作 |
| 两帧隔得太远 | 每隔 1 秒取一帧 | 很多条不同的动作序列能连接这两帧 |

### 4.5 手算例子：一堵墙和一次打滑

**设定。** 一维走廊，位置 $x \in \lbrace 0, 1, 2, \dots \rbrace$，$x = 0$ 的左边是墙。
动作有三个：左、停、右。先看确定性的版本：左是 $x \to x - 1$（在 $x = 0$ 处被墙挡住，原地不动），停是原地不动，右是 $x \to x + 1$。

**例一：可辨识的转移。** 观测到 $0 \to 1$。三个动作的似然：

| 动作 | 左 | 停 | 右 |
| --- | --- | --- | --- |
| $p(x' = 1 \mid x = 0, a)$ | 0 | 0 | 1 |

只有"右"的似然不为零。不管采集策略是什么（只要它做过"右"），后验都是 $P(\text{右}) = 1$。

**例二：墙。** 观测到 $0 \to 0$。似然：

| 动作 | 左 | 停 | 右 |
| --- | --- | --- | --- |
| $p(x' = 0 \mid x = 0, a)$ | 1 | 1 | 0 |

"左"和"停"的似然相同，后验完全由先验决定。比较两个采集者：

| | 先验 $\pi_\beta(\text{左}), \pi_\beta(\text{停}), \pi_\beta(\text{右})$ | 似然 × 先验 | 归一化后的后验 |
| --- | --- | --- | --- |
| 采集者甲（爱往左撞） | 0.6，0.1，0.3 | 0.6，0.1，0 | 左 $0.6 / 0.7 = 0.857$，停 $0.143$，右 0 |
| 采集者乙（爱停着） | 0.1，0.6，0.3 | 0.1，0.6，0 | 左 $0.1 / 0.7 = 0.143$，停 $0.857$，右 0 |

同一个物理转移，两份数据训练出来的逆动力学给出相反的答案。
如果把动作编码成 $-1, 0, +1$ 用回归目标训练，按第 4.3 节，甲的数据训练出的输出是条件均值
$0.857 \times (-1) + 0.143 \times 0 = -0.857$：一个数据里不存在的动作，又是均值塌缩。

**例三：打滑。** 换成有随机性的版本，站在 $x = 1$：
"右"有 0.8 的概率到 $x = 2$，0.2 的概率打滑留在原地；"左"同理；"停"一定留在原地。
观测到 $1 \to 1$。似然：

| 动作 | 左 | 停 | 右 |
| --- | --- | --- | --- |
| $p(x' = 1 \mid x = 1, a)$ | 0.2 | 1.0 | 0.2 |

| | 先验（左，停，右） | 似然 × 先验 | 和 | 后验（左，停，右） |
| --- | --- | --- | --- | --- |
| 均匀的随机策略 | 1/3，1/3，1/3 | 0.067，0.333，0.067 | 0.467 | 0.143，0.714，0.143 |
| 一个几乎总是往右走的专家 | 0.05，0.05，0.90 | 0.010，0.050，0.180 | 0.240 | 0.042，0.208，0.750 |

看到"没动"，在随机数据上训练的逆动力学会说"大概是停了"（0.714）；
而在专家数据的分布下，正确的推断是"多半是想往右走但打滑了"（0.750）。

这个例子说明了一个实际中很常见的坑：**用随机探索数据训练的逆动力学，去给专家的视频打标签。**
在动作可辨识的帧上没有问题；在不可辨识的帧上，它会按随机策略的习惯去猜，
而这些帧（接触、卡住、打滑）往往正是任务里最要紧的时刻。

### 4.6 推导（三）：为什么"视频预测 + 逆动力学"构成一个策略

第 4.2 节把策略定义成了两个模型的组合。现在说明这个组合在什么条件下等于我们想模仿的那个策略。

设专家策略是 $\pi^\star$。在专家的数据里，下一观测的分布（不看动作）是

$$
p^\star(o_{t+1} \mid o_t) = \sum_{a} \pi^\star(a \mid o_t) \; p(o_{t+1} \mid o_t, a)
$$

这正是第 4.4 节第三步的分母（除以 $d_\beta(o_t)$ 之后，并把 $\pi_\beta$ 换成 $\pi^\star$），也是一个在专家视频上训练的视频预测模型要拟合的分布。

**第一步：对联合分布 $p^\star(a, o_{t+1} \mid o_t)$ 用两种顺序做链式分解。**

$$
p^\star(a, o_{t+1} \mid o_t) = \underbrace{\pi^\star(a \mid o_t) \; p(o_{t+1} \mid o_t, a)}_{\text{先动作，后结果}} = \underbrace{p^\star(o_{t+1} \mid o_t) \; p^\star(a \mid o_t, o_{t+1})}_{\text{先结果，后动作}}
$$

**第二步：两边对 $o_{t+1}$ 求和。** 第一种分解里用 $\sum_{o'} p(o' \mid o, a) = 1$，只剩下 $\pi^\star(a \mid o_t)$：

$$
\pi^\star(a \mid o_t) = \sum_{o_{t+1}} p^\star(a \mid o_t, o_{t+1}) \; p^\star(o_{t+1} \mid o_t)
$$

这就是全概率公式。和第 4.2 节的组合策略逐项对比：

$$
\pi_{\theta, \xi}(a \mid o_t) = \sum_{o_{t+1}} \underbrace{q_\xi(a \mid o_t, o_{t+1})}_{\text{应当等于 } p^\star(a \mid o_t, o_{t+1})} \; \underbrace{p_\theta(o_{t+1} \mid o_t)}_{\text{应当等于 } p^\star(o_{t+1} \mid o_t)}
$$

**结论：如果视频模型拟合了专家的"下一帧分布"，逆动力学模型拟合了专家数据下的后验，两者的组合就精确地等于专家策略。**
任何策略都可以这样拆成"先决定想看到什么，再决定怎么做到"，拆法本身不损失任何东西。

**用例二验算。** 采集者甲在 $x = 0$ 处的策略是（左 0.6，停 0.1，右 0.3）。

- 视频模型应学到的下一帧分布：留在 0 的概率 $0.6 + 0.1 = 0.7$，到 1 的概率 $0.3$。
- 逆动力学：$0 \to 0$ 时左 0.857、停 0.143；$0 \to 1$ 时右 1。
- 组合：$P(\text{左}) = 0.857 \times 0.7 = 0.6$，$P(\text{停}) = 0.143 \times 0.7 = 0.1$，$P(\text{右}) = 1 \times 0.3 = 0.3$。和原策略一致。

**拆开的意义在于两半可以用不同的数据训练。** 视频模型用专家的（甚至是人类的、别的机器人的）视频，不需要动作标签；
逆动力学模型用这台机器人自己的任意带动作数据，不需要是好的演示。
代价是两半的数据分布不再一致：逆动力学里的先验是它自己训练数据的 $\pi_\beta$，不是 $\pi^\star$。
由第 4.4 节的结论二，这个不一致**只在动作不可辨识的转移上造成差别**。

再用例二看一眼差别有多大：视频模型来自甲的数据，逆动力学来自乙的数据。
组合出的策略在 $0 \to 0$ 这一支上给出左 $0.143 \times 0.7 = 0.1$、停 $0.857 \times 0.7 = 0.6$，和甲的策略不同。
但在这个例子里无所谓：左和停在墙边产生同样的结果。这是一个有用的观察：

> 完全不可辨识的动作，就是那些在这一步对观测没有影响的动作。把它们标错，这一步的后果是一样的。

危险的是另外两种情况。一是差别**此刻看不见但以后会显现**：夹爪的夹持力在画面上看不出来，
标小了，物体几秒后滑落。二是例三那样的**随机环境**：几个动作都可能产生这个观测，
但它们各自的结果分布并不相同，把"想往右但打滑"标成"停"，学出来的策略就会在该用力的时候停下。

**为什么逆动力学比策略好学。** 这是这条路线成立的经验基础（VPT，Baker et al. 2022，arXiv:2206.11795 的核心论点）：

| | 行为克隆 $\pi(a \mid o)$ | 逆动力学 $q(a \mid o, o')$ |
| --- | --- | --- |
| 要推断的东西 | 人的意图：他接下来想干什么 | 已经发生的事：这两帧之间做了什么 |
| 能看到的信息 | 只有过去 | 过去和未来（非因果） |
| 多峰性 | 强：同一画面下可以有多种合理的做法 | 弱：结果已经给定，大多数情况下动作唯一 |
| 需要的数据 | 多，且必须是好的演示 | 少，任意质量的带动作数据都行 |
| 需要理解任务吗 | 需要 | 不需要，只要认得出自己身体的运动 |

VPT 的做法是：用少量带标签的数据（约两千小时，待核对）训练逆动力学模型，
用它给约七万小时的无标签游戏视频打上动作标签，再在这些伪标签上做行为克隆。
本章第 7 节的数据引擎用的是同一招，只是被打标签的视频换成了世界模型生成的。

### 4.7 与隐动作模型的关系

Phase 9 的隐动作模型（Latent Action Model，LAM）和本节的逆动力学模型是近亲。把两者的结构画在一起：

```
   逆动力学模型（有监督）                       隐动作模型（无监督，Phase 9）

   (o_t, o_{t+1}) ──▶ 编码器 ──▶ â_t           (o_t, o_{t+1}) ──▶ 编码器 ──▶ z_t（离散，码本很小）
                                 │                                           │
                          与真实动作 a_t 比较                    (o_t, z_t) ──▶ 解码器 ──▶ ô_{t+1}
                          （需要动作标签）                                           │
                                                                    与真实的 o_{t+1} 比较
                                                                    （不需要动作标签）
```

隐动作模型的编码器，输入输出的形式和逆动力学模型完全一样：看前后两帧，输出一个"动作"。
区别在于监督信号从哪来。

| | 逆动力学模型 | 隐动作模型 |
| --- | --- | --- |
| 编码器输入 | $(o_t, o_{t+1})$ | $(o_t, o_{t+1})$ |
| 输出 | 真实的机器人动作 $a_t$ | 隐动作 $z_t$：一个没有预先定义含义的码 |
| 训练信号 | 动作标签 | 用 $(o_t, z_t)$ 重建 $o_{t+1}$，加一个很窄的信息瓶颈 |
| 需要动作标签 | 需要 | 不需要 |
| 输出能直接执行吗 | 能 | 不能。需要再用少量带标签数据学一个从 $z$ 到 $a$ 的映射 |
| 跨具身 | 每种机器人一个 | 可以在人类视频和多种机器人的视频上共用一套隐动作 |

可以这样理解：**隐动作模型是一个不知道动作长什么样的逆动力学模型**，
它把逆动力学和前向动力学（解码器）捆在一起训练，靠"瓶颈很窄，只够放下动作那么多信息"来逼编码器提取出动作。

两者共享同一个弱点，都来自第 4.4 节的贝叶斯公式。逆动力学在动作不可辨识时退回到先验；
隐动作模型则会把**两帧之间任何难以预测的变化**都编码进 $z$：相机晃动、别的物体在动、光照变化，
因为这些信息同样有助于重建下一帧。数据里与机器人动作无关的变化越多，隐动作就越"不纯"。

在机器人方向，隐动作有两种典型的用法：

- **预训练策略**：LAPA（Ye et al. 2024，arXiv:2410.11758）先在无标签视频上学隐动作，
  预训练一个预测隐动作的策略，再用少量真机数据微调，把输出换成真实动作。
- **给生成的视频打标签**：第 7 节的 DreamGen 在逆动力学模型之外，也用隐动作模型给生成视频提取伪动作。

### 4.8 代表工作与失败模式

| 工作 | 视频 / 未来预测的部分 | 动作从哪来 | 说明 |
| --- | --- | --- | --- |
| UniPi（Du et al. 2023，arXiv:2302.00111） | 文本条件的视频扩散模型，生成一段未来画面 | 单独训练的逆动力学模型，从相邻帧里解出动作 | 这条路线的代表作。"先视频后动作"的两阶段结构 |
| GR-1（Wu et al. 2023，arXiv:2312.13139） | GPT 式的 Transformer，在大规模第一人称视频上做视频预测预训练 | 同一个模型在机器人数据上微调，同时输出未来图像和动作 | 不再是两阶段；视频预测变成预训练任务和辅助任务 |
| GR-2（Cheang et al. 2024，arXiv:2410.06158） | 同上，预训练的视频规模更大 | 同上 | GR-1 的扩展 |
| Video Prediction Policy（Hu et al. 2024，arXiv:2412.14803） | 视频扩散模型，但不把视频完整生成出来 | 以视频模型内部的预测性表征为条件的动作扩散头 | "预测未来"留在特征层面，省掉生成像素的时间 |

这张表从上到下是一条清楚的演进线：**视频预测和动作生成之间的接缝越来越小**。
UniPi 里两者是通过像素连接的两个独立模型；GR-1 里它们共用一个骨干；VPP 里视频模型只提供特征。
顺着这条线再走一步，就是第 5 节的 World-Action Model。

两阶段路线的失败模式，几乎都出在两个模型的接缝上：

| 失败模式 | 现象 | 原因 |
| --- | --- | --- |
| 生成的画面不可执行 | 画面里物体凭空移动、机械臂穿过物体、手臂形状变了 | 视频模型没有物理约束，也不知道这台机器人做得到什么 |
| 逆动力学的输入越界 | 逆动力学在生成帧上输出乱跳的动作 | 逆动力学是在真实帧上训练的，生成帧上的模糊、伪影对它来说是分布外输入 |
| 动作不可辨识 | 接触、夹持这些关键时刻动作不准 | 第 4.4 节的结论三 |
| 开环执行 | 生成一整段视频、解出一整串动作、执行到底，中途不看真实画面 | 生成视频太慢，没法每步重新生成。等于放弃了 Phase 1 第 6.4 节的闭环 |
| 推理延迟 | 机器人动一下停一下 | 视频扩散模型一次生成要多步去噪 |
| 帧间隔不匹配 | 解出的动作幅度整体偏大或偏小 | 视频模型生成的帧率和逆动力学训练时的帧间隔不一致 |

### 4.9 算法

```
算法：训练逆动力学模型

输入：带动作的转移数据 D = {(o_t, a_t, o_{t+1})}（不要求是成功的演示）
重复：
 1. 取小批量 (o_t, a_t, o_{t+1})               图像 [B, C, H, W] × 2，动作 [B, D_a]
 2. 编码两帧，拼接特征（或把两帧在通道维拼接后一起编码）
 3. â = g_ξ(o_t, o_{t+1})                      形状 [B, D_a]
 4. 损失 = mean((â − a_t)²)                    离散动作时换成交叉熵
 5. 反向传播，更新 ξ
```

```
算法：视频预测策略（UniPi 式，两阶段）

输入：当前观测 o_t，指令 ℓ，视频模型 p_θ，逆动力学模型 q_ξ，重新规划间隔 T_a
 1. 视频模型生成 H 帧未来画面：ô_{t+1:t+H} ~ p_θ(· | o_t, ℓ)       形状 [H, C, H_img, W_img]
 2. 令 ô_t = o_t。对 i = 0 … H−1：
        â_{t+i} = q_ξ(ô_{t+i}, ô_{t+i+1})                          形状 [D_a]
 3. 执行 â_t … â_{t+T_a−1}，拿到新的真实观测，回到第 1 步
    （T_a = H 时就是开环执行整段计划）
```

### 4.11 常见误区

- **误区：逆动力学是前向动力学的"反函数"，环境定了它就定了。**
  实际情况：它是一个后验，等于前向动力学乘以采集策略再归一化。只有在动作可辨识时，采集策略才被约掉。
- **误区：逆动力学模型在验证集上误差很小，所以给任何视频打标签都可靠。**
  实际情况：验证集和训练集来自同一个采集策略、同一种真实画面。
  换成另一个策略的视频、或者生成的视频，输入分布和先验都变了。要在目标分布上单独检验。
- **误区：视频生成得越逼真，策略越好。**
  实际情况：逆动力学只关心机器人自己的运动是否画对了。背景纹理再逼真也没用，
  机械臂的位置差几个像素动作就错了。这是 Phase 1 第 1.6 节"预测得准和控制得好不是一回事"在这里的版本。
- **误区：这条路线不需要任何带动作的数据。**
  实际情况：视频模型那一半不需要，逆动力学那一半需要。
  省下来的是"带动作的**专家演示**"，换成了"带动作的任意数据"，后者便宜得多，但不是零。

## 5. World-Action Model

### 5.1 直觉

第 4 节的两阶段做法有一条明显的接缝：视频模型把未来画面完整地画出来，逆动力学模型再从像素里把动作读回去。
这像两个微服务之间通过截图传数据。上游辛辛苦苦渲染出每一个像素，下游只需要其中很小一部分信息；
上游不知道下游能做什么（画出了机器人做不到的动作），下游没法告诉上游哪里画错了。

把这两个服务合并成一个，共享内部状态，是很自然的重构。World-Action Model（世界-动作模型，WAM）就是这个合并的结果：
**一个模型同时建模未来的画面和未来的动作**，两者由同一个骨干网络产生，互相看得见。

合并之后还有一个额外的收获。一张记录了"画面"和"动作"两列的联合分布表，可以按不同的方式查询：
只查动作列是策略，只查画面列是视频预测，给定动作查画面是前向动力学（世界模型），给定画面查动作是逆动力学。
第 4.2 节那张表里的四个条件分布，变成了同一个模型的四种查询方式。

### 5.2 定义

World-Action Model 建模的是未来观测和未来动作的联合分布。
记未来 $k$ 步的动作块为 $A = a_{t:t+k-1}$，未来的观测为 $O' = o_{t+1:t+k}$，条件是当前及历史观测 $o_{\le t}$ 和指令 $\ell$：

$$
p_\theta(O', A \mid o_{\le t}, \ell)
$$

从这一个联合分布可以得到四个量（下面省略条件里的 $\ell$）：

| 查询 | 数学上是什么 | 相当于 | 本课在哪学过 |
| --- | --- | --- | --- |
| 策略 | 边缘分布 $p_\theta(A \mid o_{\le t})$ | Diffusion Policy | 第 3 节 |
| 视频预测 | 边缘分布 $p_\theta(O' \mid o_{\le t})$ | 不带动作条件的视频模型 | 第 4 节 |
| 前向动力学 | 条件分布 $p_\theta(O' \mid o_{\le t}, A)$ | 动作条件的世界模型 | Phase 9 |
| 逆动力学 | 条件分布 $p_\theta(A \mid o_{\le t}, O')$ | 逆动力学模型 | 第 4 节 |

这个术语的边界目前并不统一。有的综述把所有"训练时预测未来画面的机器人策略"都算进来（包括 GR-1、VPP），
有的只指显式建模联合分布的模型（待核对：README 论文表里的三篇 2026 年综述各自的划分口径，读综述时留意）。
本课程采用 README 里的说法：**把视频预测和动作生成放进同一个模型**，并以联合分布的观点来理解它。

### 5.3 推导：用两个噪声水平切换四种查询

怎么让一个网络支持上面四种查询？Unified World Models（Zhu et al. 2025，arXiv:2504.02792，下称 UWM）的办法很简洁：
把第 3.6 节的动作扩散和 Phase 9 的视频扩散放进同一个 Transformer，但**两种模态各用一个独立的扩散步**。

**设定。** 记动作块的扩散步为 $j_a$，未来观测的扩散步为 $j_o$，都在 $\lbrace 0, 1, \dots, J \rbrace$ 里取值。
$j = 0$ 表示完全干净，$j = J$ 表示纯噪声。加噪方式和第 3.6 节相同：

$$
A^{(j_a)} = \sqrt{\bar\alpha_{j_a}} \, A + \sqrt{1 - \bar\alpha_{j_a}} \, \eta_a, \qquad
{O'}^{(j_o)} = \sqrt{\bar\alpha_{j_o}} \, O' + \sqrt{1 - \bar\alpha_{j_o}} \, \eta_o
$$

网络同时看到两个加噪的输入和两个扩散步，同时预测两份噪声：

$$
(\hat\eta_a, \hat\eta_o) = \eta_\theta\big(A^{(j_a)}, \, {O'}^{(j_o)}, \, j_a, \, j_o, \, o_{\le t}\big)
$$

训练时 $j_a$ 和 $j_o$ **各自独立采样**，损失是两项去噪误差之和：

$$
\mathcal{L}_{\text{WAM}} = \mathbb{E}_{(o_{\le t}, A, O') \sim \mathcal{D}, \; j_a, \; j_o, \; \eta_a, \; \eta_o} \Big[ \lambda_a \, \Vert \eta_a - \hat\eta_a \Vert^2 + \lambda_o \, \Vert \eta_o - \hat\eta_o \Vert^2 \Big]
$$

这是 Phase 9 的 Diffusion Forcing 的同一个想法。那里是"每一帧一个独立的噪声水平"，这里是"每一种模态一个独立的噪声水平"。

**关键的两条性质。**

**性质一：某个模态取纯噪声，等价于把它边缘化掉。** 以动作为例。当 $j_a = J$ 时，$\bar\alpha_J \approx 0$，
输入的 $A^{(J)} \approx \eta_a$ 是一个和真实动作 $A$ 无关的随机数。设 $\tilde{A}$ 与 $(A, O', o)$ 独立，则

$$
p(O' \mid o, \tilde{A}) = \frac{p(O', \tilde{A} \mid o)}{p(\tilde{A} \mid o)} = \frac{p(O' \mid o) \; p(\tilde{A})}{p(\tilde{A})} = p(O' \mid o)
$$

第一个等号是条件概率的定义，第二个等号用了独立性。
也就是说，在"动作输入是纯噪声"这个条件下，网络要去噪的未来观测服从的就是边缘分布 $p(O' \mid o)$。
它被训练成了一个不看动作的视频预测模型。

**性质二：某个模态取干净值，等价于以它为条件。** 当 $j_a = 0$ 时输入的就是真实动作 $A$，
网络要去噪的未来观测服从 $p(O' \mid o, A)$。它被训练成了动作条件的世界模型。

把两条性质用在两个模态上，得到四种查询的"配方"：

| 查询 | 动作的扩散步 $j_a$ | 观测的扩散步 $j_o$ | 采样时做什么 |
| --- | --- | --- | --- |
| 策略 $p(A \mid o)$ | 从 $J$ 去噪到 0 | 固定为 $J$（纯噪声） | 只对动作去噪 |
| 视频预测 $p(O' \mid o)$ | 固定为 $J$（纯噪声） | 从 $J$ 去噪到 0 | 只对观测去噪 |
| 前向动力学 $p(O' \mid o, A)$ | 固定为 0（给定的干净动作） | 从 $J$ 去噪到 0 | 只对观测去噪 |
| 逆动力学 $p(A \mid o, O')$ | 从 $J$ 去噪到 0 | 固定为 0（给定的干净观测） | 只对动作去噪 |
| 联合采样 $p(O', A \mid o)$ | 从 $J$ 去噪到 0 | 从 $J$ 去噪到 0 | 两者一起去噪 |

**一个直接的好处：没有动作标签的视频也能用来训练。** 对一段只有画面的视频，把动作输入填成纯噪声、
令 $j_a = J$、只算观测那一项损失，这个样本训练的就是"视频预测"那一行。
带动作的机器人数据和不带动作的视频可以混在同一个批次里训练同一个网络，这是 UWM 论文强调的预训练方式。

**手算例子：一张联合分布表的四种查询。** 把问题缩到最小。给定当前画面，动作只有两种（往左推、往右推），
未来画面只有两种（块左移、块右移）。专家数据里的联合分布是：

| | 块左移 | 块右移 | 行和（策略） |
| --- | --- | --- | --- |
| **往左推** | 0.45 | 0.05 | 0.50 |
| **往右推** | 0.10 | 0.40 | 0.50 |
| **列和（视频预测）** | 0.55 | 0.45 | 1.00 |

四种查询的结果：

| 查询 | 计算 | 结果 |
| --- | --- | --- |
| 策略 | 行和 | $P(\text{左推}) = 0.50$，$P(\text{右推}) = 0.50$ |
| 视频预测 | 列和 | $P(\text{左移}) = 0.55$，$P(\text{右移}) = 0.45$ |
| 前向动力学 | 每行除以行和 | $P(\text{左移} \mid \text{左推}) = 0.45 / 0.50 = 0.90$；$P(\text{右移} \mid \text{右推}) = 0.40 / 0.50 = 0.80$ |
| 逆动力学 | 每列除以列和 | $P(\text{左推} \mid \text{左移}) = 0.45 / 0.55 = 0.818$；$P(\text{右推} \mid \text{右移}) = 0.40 / 0.45 = 0.889$ |

顺手验证第 4.6 节的恒等式（策略 = 逆动力学 × 视频预测，再对未来画面求和）：

$$
P(\text{左推}) = \underbrace{0.818 \times 0.55}_{\text{经过"左移"}} + \underbrace{\frac{0.05}{0.45} \times 0.45}_{\text{经过"右移"}} = 0.45 + 0.05 = 0.50
$$

两阶段方法是先按列和采样一个未来画面，再按那一列的条件分布采样动作；
World-Action Model 是直接把整张表学下来。数学上两者表示的是同一个分布，
差别全在工程上：是否共享表征、是否必须把未来画面完整生成出来、能否混用没有动作的数据。

**为什么联合训练对策略有帮助。** 即使部署时只用"策略"这一种查询，训练时预测未来画面也有好处，原因和 Phase 1 第 4.1 节说过的一样：
动作标签是低维的（每步几个数），提供的监督信号很稀薄；未来画面是高维的，每一步提供成千上万个监督信号，
逼着骨干网络学会"这个场景接下来会怎么变"。GR-1 的实验论点就是视频预测预训练能提高下游操作任务的成功率和泛化能力。

**推理时可以不生成视频。** 策略那一行的配方里，观测输入固定为纯噪声，不需要对它去噪。
省掉视频的去噪是这类模型能实时运行的关键。Unified Video Action Model（Li et al. 2025，arXiv:2503.00200，下称 UVA）
把这一点做成了结构上的分离：骨干学一个视频和动作共用的联合隐表示，后面接两个轻量的扩散头分别解码视频和动作，
当策略用时只跑动作头；并用"随机遮住一部分输入"的训练方式让同一个模型承担策略、前向动力学、逆动力学、视频预测几种功能。

### 5.4 代表工作

| 工作 | 结构要点 | 怎么切换功能 | 部署时生成视频吗 |
| --- | --- | --- | --- |
| GR-1 / GR-2（arXiv:2312.13139 / 2410.06158） | 自回归 Transformer，同时输出未来图像和动作 | 不切换，固定为"策略 + 辅助的未来图像预测" | 生成（作为辅助输出） |
| UVA（arXiv:2503.00200） | 联合隐表示 + 两个解耦的扩散头 | 训练时随机遮住输入的一部分 | 当策略用时不生成 |
| UWM（arXiv:2504.02792） | 一个 Transformer 里耦合动作扩散与视频扩散 | 两个独立的扩散步（第 5.3 节） | 当策略用时不生成 |
| Genie Envisioner（Liao et al. 2025，arXiv:2508.05635） | 平台式：视频扩散基座（GE-Base）+ 动作解码器（GE-Act）+ 动作条件的神经仿真器（GE-Sim） | 不同组件承担不同功能 | 视组件而定 |

Genie Envisioner 值得单独提一句：它把本章的两种用法（当策略、当仿真器）连同配套的评测基准放在同一个视频基座上，
是"四种用法是同一类模型的不同用途"（第 1.9 节）的一个具体例子。

失败模式：

| 失败模式 | 说明 |
| --- | --- |
| 两个目标打架 | 视频那一项的损失数值和梯度规模远大于动作那一项，骨干被画面细节占满。权重 $\lambda_a$、$\lambda_o$ 要调 |
| 画面好不等于动作好 | 视频预测指标提高了，成功率没动。又是目标不匹配（Phase 1 第 1.6 节） |
| 一专多能，样样稀松 | 四种查询共用一份参数，每一种都可能不如专门训练的单一模型 |
| 计算量 | 视频 token 数远多于动作 token，训练成本主要花在视频上 |
| 自己评估自己 | 用模型的"前向动力学"查询去评估它自己的"策略"查询，两者的错误是相关的（第 6.6 节） |

### 5.5 算法

```
算法：World-Action Model 训练（UWM 式，两个独立的扩散步）

重复：
 1. 取小批量。带动作的样本：(o_≤t, A, O')；只有视频的样本：(o_≤t, O')
 2. 对每个样本独立采样：j_a ~ Uniform{0…J}，j_o ~ Uniform{0…J}
    只有视频的样本：令 j_a = J，动作输入用纯噪声填充
 3. 加噪：A^(j_a)，O'^(j_o)                    动作 [B, K, D_a]，观测隐表示 [B, T', N_tok, D]
 4. (η̂_a, η̂_o) = η_θ(A^(j_a), O'^(j_o), j_a, j_o, o_≤t)
 5. 损失 = λ_a · mean((η_a − η̂_a)²) + λ_o · mean((η_o − η̂_o)²)
    只有视频的样本不计动作那一项
 6. 反向传播，更新 θ
```

```
算法：四种查询的采样

输入：o_≤t；模式 ∈ {policy, video, forward, inverse}；可选的给定动作 A 或给定未来观测 O'
 policy  ： Õ ← 纯噪声，j_o 固定为 J；对动作从 J 去噪到 0，返回 A
 video   ： Ã ← 纯噪声，j_a 固定为 J；对观测从 J 去噪到 0，返回 O'
 forward ： 动作输入 ← 给定的 A，j_a 固定为 0；对观测从 J 去噪到 0，返回 O'
 inverse ： 观测输入 ← 给定的 O'，j_o 固定为 0；对动作从 J 去噪到 0，返回 A
```

### 5.7 常见误区

- **误区：World-Action Model 推理时必须先生成视频再出动作，所以一定很慢。**
  实际情况：这是两阶段方法（UniPi）的特点。UVA、UWM 当策略用时跳过视频生成，速度接近普通的扩散策略。
- **误区：把四种功能塞进一个模型，是为了省参数。**
  实际情况：主要动机是让动作学习从视频预测里借监督信号，以及能用上没有动作标签的视频。省参数是次要的。
- **误区：联合模型的前向动力学查询可以直接拿来评估它自己的策略。**
  实际情况：两者共享表征，错误高度相关。策略在哪些状态上理解错了，世界模型多半也在那里理解错，
  评估结果会偏乐观。评估用的世界模型最好独立于被评估的策略。
- **误区：World-Action Model 和 VLA 是对立的两条路线。**
  实际情况：两者在合流。越来越多的 VLA 在训练里加入未来画面或未来特征的预测，
  而 World-Action Model 也普遍带上了语言条件。区别更多在于预训练骨干来自视觉语言模型还是视频模型。

## 6. 把世界模型当仿真器：策略评估

### 6.1 直觉

Phase 1 把世界模型比作预发布环境。那时我们用它来**做决策**（在里面试动作）。
这一节用它来**做测试**：把一个已经训练好的策略放进世界模型里闭环运行，数它成功了多少次，
以此代替在真机上跑几十个回合。

动机很实际。第 1.7 节算过，真机评估又慢又有噪声；而模型开发的每一步都需要评估：
哪个检查点最好、这次改动有没有用、两个方法谁强。评估是整个迭代循环里最慢的一环。

做过推荐系统或搜索的人对这个处境很熟悉：线上 A/B 实验是金标准，但慢而且贵，
所以平时用**离线指标**来筛选模型。离线指标从来不等于线上指标，没有人指望离线 AUC 的数值等于线上点击率。
人们对离线指标的要求只有一条：**它说 A 比 B 好的时候，线上 A 确实比 B 好。**
一个离线指标值不值得信，要看它和线上结果的相关性，而这个相关性本身要拿一批已经做过 A/B 的模型来验证。

把"离线指标"换成"世界模型里的成功率"，把"线上 A/B"换成"真机成功率"，就是本节的全部内容。

### 6.2 定义

**在世界模型里评估一个策略**，需要三样东西：

| 组件 | 作用 | 可能出错的地方 |
| --- | --- | --- |
| 动作条件的世界模型 $p_\theta(o_{t+1} \mid o_{\le t}, a_t)$ | 代替真实环境，根据策略给的动作生成下一帧 | 预测不准；长时程漂移；对动作不敏感 |
| 初始条件 | 每个回合从哪一帧开始。通常取真机拍下的真实初始画面 | 初始画面的分布和真实评估时不一致 |
| 成功判定器 $g(\hat{o}_{0:T}) \in \lbrace 0, 1 \rbrace$ | 看生成的整段视频，判断任务是否完成。可以是人、训练出来的分类器，或视觉语言模型 | 判定本身有错；被生成画面的伪影骗过 |

闭环展开的过程：

$$
\hat{o}_0 = o_0, \qquad a_t \sim \pi(\cdot \mid \hat{o}_{\le t}), \qquad \hat{o}_{t+1} \sim p_\theta(\cdot \mid \hat{o}_{\le t}, a_t), \qquad t = 0, \dots, T - 1
$$

```
              ┌────────────────────── 世界模型里的一个回合 ──────────────────────┐
              │                                                                │
   真实初始画面 │   ô_0 ──▶ 策略 π ──▶ a_0 ──▶ 世界模型 ──▶ ô_1 ──▶ 策略 π ──▶ a_1 ──▶ ··· ──▶ ô_T
   o_0 ───────▶│    ▲                                        │                              │
              │    └────────────────────────────────────────┘                              │
              │          策略看到的是世界模型生成的画面，不是真实画面                          │
              └────────────────────────────────────────────────────────────────┬───────────┘
                                                                               ▼
                                                                    成功判定器 g ──▶ 0 或 1
```

对第 $i$ 个策略跑 $n$ 个这样的回合，成功的比例记作 $\hat{y}_i$（**模型里的成功率**）。
同一个策略在真机上测得的成功率记作 $y_i$（**真实成功率**）。

这和 Phase 9 评估视频模型的方式有本质区别：

| | 开环评估（Phase 9 用过） | 闭环评估（本节） |
| --- | --- | --- |
| 动作从哪来 | 数据集里录好的动作，原样重放 | 被评估的策略根据生成的画面现场给出 |
| 比较对象 | 生成的帧与数据集里的真实帧 | 没有逐帧的真值可比 |
| 指标 | PSNR、SSIM、LPIPS、FVD | 成功率，以及它与真实成功率的一致程度 |
| 模型访问的状态 | 数据集里出现过的 | 策略自己走出来的，可能没出现过 |
| 回答的问题 | 模型能不能复现已发生的事 | 模型能不能预言没发生过的事的结果 |

第二列才是当仿真器用时真正要的能力，也难得多：一个差的策略会把场景带到演示数据从未覆盖的状态
（物体被推到桌子边上、夹爪抓空），模型必须在那里也预测对。

**评估的评估。** 手上有 $N$ 个策略，各有一对数 $(y_i, \hat{y}_i)$。衡量世界模型作为评估器好不好，
就是衡量这 $N$ 对数的一致程度。本节给出三个指标：Pearson 相关系数、Spearman 秩相关、MMRV。

### 6.3 推导（一）：模型里的成功率为什么会偏

先回答一个基本问题：模型的单步误差，会让成功率偏多少？
用状态层面的记号（把 $o_{\le t}$ 概括成状态 $s_t$），真实转移是 $p(\cdot \mid s, a)$，模型是 $p_\theta(\cdot \mid s, a)$。

**假设。** 对策略会遇到的所有状态和动作，模型与真实转移的总变差距离（total variation distance）不超过 $\varepsilon_m$：

$$
D_{\mathrm{TV}}\big(p_\theta(\cdot \mid s, a), \; p(\cdot \mid s, a)\big) \le \varepsilon_m
$$

总变差距离有一个直观的等价说法：可以构造一种"联合抽样"的方式，从两个分布里各抽一个样本，
使得两个样本**相同**的概率等于 $1 - D_{\mathrm{TV}}$。也就是说，$\varepsilon_m$ 是"模型这一步和真实世界走得不一样"的概率上界。

**第一步：让两条轨迹尽量同步。** 真实回合和模型里的回合从同一个初始状态出发，用同一个策略。
只要到第 $t$ 步为止两条轨迹完全相同，策略给出的动作就相同，于是下一步两者仍然相同的概率至少是 $1 - \varepsilon_m$。

**第二步：整个回合都相同的概率。** 连续 $T$ 步都没分开：

$$
P(\text{两条轨迹完全相同}) \ge (1 - \varepsilon_m)^T \ge 1 - T \varepsilon_m
$$

第二个不等号是伯努利不等式 $(1 - x)^T \ge 1 - Tx$。

**第三步：成功率之差。** 成功与否是轨迹的函数，取值 0 或 1。两条轨迹相同时，成功判定相同，差为 0；
不同时，差的绝对值最多是 1。所以

$$
\lvert \hat{y} - y \rvert \le P(\text{两条轨迹不同}) \le 1 - (1 - \varepsilon_m)^T \le T \varepsilon_m
$$

**手算例子。** 设 $\varepsilon_m = 0.002$：每一步有千分之二的概率，模型里发生的事和真实世界不一样。

| 回合长度 $T$ | $T \varepsilon_m$ | $1 - (1 - \varepsilon_m)^T$ |
| --- | --- | --- |
| 100 | 0.20 | $1 - 0.998^{100} = 1 - 0.819 = 0.181$ |
| 300 | 0.60 | $1 - 0.998^{300} = 1 - 0.549 = 0.451$ |

单步 99.8% 的"保真度"，300 步的回合里成功率的偏差上界已经是 45 个百分点。
这和 Phase 1 第 5.3 节是同一个故事：单步误差沿着展开累积。那里的结论是"单步准不代表多步能用"，
这里的结论是"**不要指望模型里的成功率在绝对数值上等于真实成功率**"。

**那凭什么还能用？第二个小推导。** 记每个策略的偏差为 $b_i = \hat{y}_i - y_i$。对任意两个策略 $i$、$j$：

$$
\hat{y}_i - \hat{y}_j = (y_i - y_j) + (b_i - b_j)
$$

- 如果所有策略的偏差**相同**（$b_i = b_j$），第二项为零，模型里的排序和真实排序完全一致，不管偏差本身有多大。
- 如果偏差各不相同但都在 $\lvert b_i \rvert \le \delta$ 之内，则 $\lvert b_i - b_j \rvert \le 2\delta$。
  只要真实差距 $y_i - y_j > 2\delta$，就有 $\hat{y}_i - \hat{y}_j > 0$，这一对的排序是对的。
  排错的只可能是真实差距不超过 $2\delta$ 的那些对。

**排序是否正确，取决于偏差在策略之间的差异，而不取决于偏差本身的大小。**
一个对所有策略都悲观 30 个点的世界模型，是个好评估器；一个平均很准、但偏偏对某一类策略特别乐观的世界模型，是个坏评估器。
这就是为什么下面三个指标都在衡量"一致性"，没有一个在衡量"绝对误差"。

麻烦在于偏差**并不**天然相同。$\varepsilon_m$ 取决于策略去了哪些状态：留在演示数据附近的策略，模型预测得准；
跑到数据之外的策略（特别差的，或者特别新颖的），模型预测得差。偏差和策略本身相关，这是第 6.6 节的主题。

### 6.4 推导（二）：三个一致性指标

#### Pearson 相关系数

**定义。** 记 $\bar{y}$、$\bar{\hat{y}}$ 为两组数各自的平均值。

$$
\rho_{\mathrm{P}} = \frac{\sum_{i=1}^{N} (y_i - \bar{y})(\hat{y}_i - \bar{\hat{y}})}{\sqrt{\sum_{i=1}^{N} (y_i - \bar{y})^2} \; \sqrt{\sum_{i=1}^{N} (\hat{y}_i - \bar{\hat{y}})^2}}
$$

分子是两组偏离量的内积，分母是两组偏离量各自的长度。它就是"去掉均值后两个向量夹角的余弦"。

**性质一：取值在 $[-1, 1]$。** 记偏离量 $e_i = y_i - \bar{y}$，$\hat{e}_i = \hat{y}_i - \bar{\hat{y}}$。
由柯西-施瓦茨不等式 $\big(\sum_i e_i \hat{e}_i\big)^2 \le \sum_i e_i^2 \sum_i \hat{e}_i^2$，分子的绝对值不超过分母。

**性质二：对正的仿射变换不变。** 把模型里的成功率整体变换成 $\hat{y}'_i = c_1 \hat{y}_i + c_0$（$c_1 > 0$）。
均值变成 $c_1 \bar{\hat{y}} + c_0$，所以偏离量变成 $\hat{e}'_i = c_1 \hat{e}_i$。代入定义：

$$
\rho'_{\mathrm{P}} = \frac{\sum_i e_i \cdot c_1 \hat{e}_i}{\sqrt{\sum_i e_i^2} \; \sqrt{c_1^2 \sum_i \hat{e}_i^2}} = \frac{c_1 \sum_i e_i \hat{e}_i}{c_1 \sqrt{\sum_i e_i^2} \; \sqrt{\sum_i \hat{e}_i^2}} = \rho_{\mathrm{P}}
$$

这条性质有两面。好的一面：世界模型整体偏悲观或偏乐观、把差距压缩或放大，都不影响 Pearson，
它衡量的是"线性关系有多强"，这正是第 6.3 节说的"不看绝对数值"。
坏的一面：$\rho_{\mathrm{P}} = 1$ 不代表 $\hat{y}_i = y_i$。

**性质三：只衡量线性关系，对极端值敏感。** 如果模型里的成功率是真实成功率的一个单调但弯曲的函数
（比如在高成功率处饱和），排序完全正确，Pearson 也会小于 1。
反过来，$N$ 很小时，一个离群的策略（比如一个成功率为 0 的随机策略）就能把 Pearson 拉到很高，掩盖其余策略之间的混乱。

#### Spearman 秩相关

**定义。** 先把两组数各自换成名次（rank，最小的记 1，最大的记 $N$），再对名次算 Pearson 相关系数。
记第 $i$ 个策略的真实名次为 $u_i$，模型里的名次为 $v_i$，名次差 $d_i = u_i - v_i$。

**推导：没有并列时的简化公式。** 没有并列时，$u$ 和 $v$ 都是 $1, 2, \dots, N$ 的一个排列。

第一步，名次的平均值。由 $1 + 2 + \dots + N = N(N+1)/2$：

$$
\bar{u} = \bar{v} = \frac{N + 1}{2}
$$

第二步，名次的偏离平方和。由 $1^2 + 2^2 + \dots + N^2 = N(N+1)(2N+1)/6$：

$$
\sum_i (u_i - \bar{u})^2 = \sum_i u_i^2 - N \bar{u}^2 = \frac{N(N+1)(2N+1)}{6} - \frac{N(N+1)^2}{4} = \frac{N(N+1)}{12} \big[ 2(2N+1) - 3(N+1) \big] = \frac{N(N^2 - 1)}{12}
$$

$v$ 的偏离平方和相同。所以 Pearson 公式的分母就是 $N(N^2 - 1)/12$。

第三步，把分子用名次差表示。展开 $\sum_i d_i^2 = \sum_i (u_i - v_i)^2 = \sum_i u_i^2 + \sum_i v_i^2 - 2 \sum_i u_i v_i$，
而 $\sum_i u_i^2 = \sum_i v_i^2$，于是

$$
\sum_i u_i v_i = \sum_i u_i^2 - \frac{1}{2} \sum_i d_i^2
$$

分子是

$$
\sum_i (u_i - \bar{u})(v_i - \bar{v}) = \sum_i u_i v_i - N \bar{u}^2 = \underbrace{\sum_i u_i^2 - N \bar{u}^2}_{= \, N(N^2 - 1)/12} - \frac{1}{2} \sum_i d_i^2
$$

第四步，分子除以分母：

$$
\rho_{\mathrm{S}} = 1 - \frac{6 \sum_{i=1}^{N} d_i^2}{N(N^2 - 1)}
$$

有并列时，并列的策略取它们名次的平均值，然后直接按 Pearson 的定义算，不能用这个简化公式。

**性质一：对任何单调递增的变换不变。** 名次只取决于大小顺序。模型里的成功率不管怎么被压缩、饱和、平移，
只要顺序没变，Spearman 就不变。它比 Pearson 更直接地回答"排序对不对"。

**性质二：只看名次，不看差距。** 把两个真实成功率差 2 个点的策略排反，和把两个差 20 个点的相邻策略排反，
在 Spearman 眼里是同样大小的错误（名次差都是 1）。可是前一种错误无关紧要（真机评估自己都分不清这两个策略），
后一种会让你选错模型。这是它的主要缺点，也是 MMRV 要补的地方。

#### MMRV：平均最大排序违例

MMRV（Mean Maximum Rank Violation）出自 SIMPLER（Li et al. 2024，*Evaluating Real-World Robot Manipulation Policies in Simulation*，arXiv:2405.05941）。
那篇论文研究的是用物理仿真器评估真机策略，提出用 MMRV 和 Pearson 相关系数两个指标衡量仿真评估与真实评估的一致性；
这套指标同样适用于世界模型当评估器的情形（README 论文表里各篇具体报告了哪些指标，待核对）。
下面的定义按论文的写法给出，细节（特别是出现并列时怎么算）待核对。

**定义。** 先对每一对策略 $(i, j)$ 定义"排序违例"：如果模型里两者的先后顺序和真实的先后顺序不一致，
违例的大小是两者真实成功率之差；一致则为 0。

$$
\mathrm{RV}(i, j) = \lvert y_i - y_j \rvert \cdot \mathbb{1}\big[ (\hat{y}_i < \hat{y}_j) \neq (y_i < y_j) \big]
$$

然后对每个策略取它参与的最严重的一次违例，再对所有策略取平均：

$$
\mathrm{MMRV} = \frac{1}{N} \sum_{i=1}^{N} \max_{1 \le j \le N} \mathrm{RV}(i, j)
$$

**性质。**

- **越小越好，0 表示没有任何一对被排反。** 它的单位和成功率相同，取值在 $[0, 1]$。
- **按真实差距加权。** 排反两个真实差距很小的策略几乎不受罚，排反两个差距很大的策略受重罚。
  这正好补上 Spearman 的缺点，也自然地容忍了真实评估自身的噪声（第 1.7 节）：真机上本来就分不清的两个策略，排反了也不该算错。
- **取最大值，看最坏情况。** 对每个策略问的是"关于它，世界模型犯的最离谱的一次排序错误有多大"。
- **只依赖模型里的顺序。** 和 Spearman 一样，对 $\hat{y}$ 做任何单调递增变换都不改变 MMRV。它完全不关心绝对数值。
- **与第 6.3 节的联系。** 如果每个策略的偏差都满足 $\lvert b_i \rvert \le \delta$，被排反的每一对真实差距都不超过 $2\delta$，
  所以 $\mathrm{MMRV} \le 2\delta$。

**可以这样读它**：MMRV = 0.05 的意思是，平均而言，世界模型对每个策略犯的最严重的排序错误，
也只是把它和一个真实成功率相差 5 个点的策略排反了。

### 6.5 手算例子：五个策略，四个世界模型

五个策略 A–E（比如第 3 节训练的不同方法、不同训练程度的策略），在真实环境里的成功率：

| 策略 | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 真实成功率 $y$ | 0.20 | 0.45 | 0.50 | 0.70 | 0.90 |
| 真实名次 $u$ | 1 | 2 | 3 | 4 | 5 |

平均值 $\bar{y} = (0.20 + 0.45 + 0.50 + 0.70 + 0.90) / 5 = 0.55$。
偏离量 $e_i = y_i - \bar{y}$ 是 $-0.35, -0.10, -0.05, 0.15, 0.35$，平方和是

$$
0.1225 + 0.0100 + 0.0025 + 0.0225 + 0.1225 = 0.2800
$$

**世界模型甲**给出的成功率，完整算一遍三个指标：

| 策略 | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 模型里的成功率 $\hat{y}$ | 0.30 | 0.55 | 0.50 | 0.60 | 0.80 |
| 模型里的名次 $v$ | 1 | 3 | 2 | 4 | 5 |
| 名次差 $d = u - v$ | 0 | −1 | 1 | 0 | 0 |

*Pearson。* 平均值 $(0.30 + 0.55 + 0.50 + 0.60 + 0.80) / 5 = 0.55$。偏离量 $\hat{e}_i$ 是 $-0.25, 0, -0.05, 0.05, 0.25$。

$$
\begin{aligned}
\sum_i \hat{e}_i^2 &= 0.0625 + 0 + 0.0025 + 0.0025 + 0.0625 = 0.1300 \\
\sum_i e_i \hat{e}_i &= (-0.35)(-0.25) + (-0.10)(0) + (-0.05)(-0.05) + (0.15)(0.05) + (0.35)(0.25) \\
&= 0.0875 + 0 + 0.0025 + 0.0075 + 0.0875 = 0.1850 \\
\rho_{\mathrm{P}} &= \frac{0.1850}{\sqrt{0.2800 \times 0.1300}} = \frac{0.1850}{\sqrt{0.0364}} = \frac{0.1850}{0.1908} = 0.970
\end{aligned}
$$

*Spearman。* 名次差的平方和是 $0 + 1 + 1 + 0 + 0 = 2$，$N(N^2 - 1) = 5 \times 24 = 120$：

$$
\rho_{\mathrm{S}} = 1 - \frac{6 \times 2}{120} = 0.90
$$

*MMRV。* 逐对检查 10 对策略的顺序。A 在两边都是最低，E 在两边都是最高，D 在两边都排第四；
唯一不一致的是 (B, C)：真实 $0.45 < 0.50$，模型里 $0.55 > 0.50$。这一对的违例大小是 $\lvert 0.45 - 0.50 \rvert = 0.05$。

| 策略 | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 最大违例 | 0 | 0.05 | 0.05 | 0 | 0 |

$$
\mathrm{MMRV} = \frac{0 + 0.05 + 0.05 + 0 + 0}{5} = 0.02
$$

*平均绝对误差*（作为对照）：$(0.10 + 0.10 + 0 + 0.10 + 0.10) / 5 = 0.08$。

**再看另外三个世界模型。** 计算过程相同，这里只列关键步骤。

| 世界模型 | A | B | C | D | E | 它错在哪 |
| --- | --- | --- | --- | --- | --- | --- |
| 真实 $y$ | 0.20 | 0.45 | 0.50 | 0.70 | 0.90 | |
| 甲 | 0.30 | 0.55 | 0.50 | 0.60 | 0.80 | 把差距压缩了；排反了很接近的 B 和 C |
| 乙 | 0.10 | 0.225 | 0.25 | 0.35 | 0.45 | 所有成功率都只有真实值的一半 |
| 丙 | 0.20 | 0.45 | 0.50 | 0.85 | 0.75 | 前三个完全准确；排反了最好的两个 |
| 丁 | 0.20 | 0.45 | 0.50 | 0.70 | 0.15 | 前四个完全准确；最好的策略在模型里几乎全失败 |

- **乙**：$\hat{y}_i = 0.5 \, y_i$ 是正的仿射变换，由性质二 $\rho_{\mathrm{P}} = 1$；顺序没变，$\rho_{\mathrm{S}} = 1$，$\mathrm{MMRV} = 0$。
  平均绝对误差 $(0.10 + 0.225 + 0.25 + 0.35 + 0.45) / 5 = 0.275$。
- **丙**：平均值 0.55，偏离量 $-0.35, -0.10, -0.05, 0.30, 0.20$，平方和 $0.1225 + 0.01 + 0.0025 + 0.09 + 0.04 = 0.2650$。
  内积 $0.1225 + 0.0100 + 0.0025 + 0.0450 + 0.0700 = 0.2500$。
  $\rho_{\mathrm{P}} = 0.25 / \sqrt{0.28 \times 0.265} = 0.25 / 0.2724 = 0.918$。
  名次差只在 D、E 上是 $\mp 1$，$\rho_{\mathrm{S}} = 0.90$。
  被排反的是 (D, E)，真实差距 0.20，$\mathrm{MMRV} = (0.20 + 0.20) / 5 = 0.08$。
  平均绝对误差 $(0 + 0 + 0 + 0.15 + 0.15) / 5 = 0.06$。
- **丁**：平均值 0.40，偏离量 $-0.20, 0.05, 0.10, 0.30, -0.25$，平方和 $0.04 + 0.0025 + 0.01 + 0.09 + 0.0625 = 0.2050$。
  内积 $0.0700 - 0.0050 - 0.0050 + 0.0450 - 0.0875 = 0.0175$。
  $\rho_{\mathrm{P}} = 0.0175 / \sqrt{0.28 \times 0.205} = 0.0175 / 0.2396 = 0.073$。
  模型里的名次是 E 1、A 2、B 3、C 4、D 5，名次差 $-1, -1, -1, -1, 4$，平方和 20，$\rho_{\mathrm{S}} = 1 - 120 / 120 = 0$。
  E 和其余四个都被排反，真实差距分别是 0.70、0.45、0.40、0.20。每个策略的最大违例：A 0.70、B 0.45、C 0.40、D 0.20、E 0.70。
  $\mathrm{MMRV} = 2.45 / 5 = 0.49$。平均绝对误差 $0.75 / 5 = 0.15$。

汇总：

| 世界模型 | 平均绝对误差 | Pearson | Spearman | MMRV | 按模型选出的最优策略 | 选对了吗 |
| --- | --- | --- | --- | --- | --- | --- |
| 甲 | 0.08 | 0.970 | 0.90 | 0.02 | E | 对 |
| 乙 | 0.275 | 1.000 | 1.00 | 0.00 | E | 对 |
| 丙 | 0.06 | 0.918 | 0.90 | 0.08 | D | 错 |
| 丁 | 0.15 | 0.073 | 0.00 | 0.49 | D | 错 |

这张表值得逐行读：

1. **平均绝对误差把结论完全弄反了。** 它认为丙最好、乙最差。而乙是唯一一个所有排序都正确的评估器，丙却会让你部署错误的策略。
   这就是"排序一致性比绝对数值更重要"的具体含义：我们用评估来**做比较和做选择**，而不是来读一个数。
2. **甲和丙的 Spearman 相同（0.90），MMRV 差四倍。** 两者都只排反了一对相邻名次的策略，Spearman 分不出来。
   但甲排反的是真实差距 5 个点的一对（第 1.7 节：这点差距在真机上本来就测不准），丙排反的是差距 20 个点的冠亚军。
3. **丁有四个策略预测得分毫不差，却是最没用的评估器。** 一个策略上的失误毁掉了全部排序。
   而且失误恰好出在最好的策略上，这并非巧合，见第 6.6 节。
4. **Pearson 和 MMRV 互补。** Pearson 对"差距被非线性地扭曲"敏感，MMRV 对"差距大的被排反"敏感。SIMPLER 两个都报告。

**五个点的相关系数有多可信。** 假设世界模型给出的排序完全是随机的，$N = 5$ 时共有 $5! = 120$ 种排列。
其中 $\rho_{\mathrm{S}} \ge 0.9$ 的有几种？$\rho_{\mathrm{S}} = 1$ 只有 1 种（完全一致）；
$\rho_{\mathrm{S}} = 0.9$ 要求名次差平方和为 2，只能是交换一对相邻名次，有 4 种。合计 5 种：

$$
P(\rho_{\mathrm{S}} \ge 0.9 \mid \text{随机排序}) = \frac{5}{120} \approx 4.2\%
$$

只有 4 个策略时更糟：交换一对相邻名次得到 $\rho_{\mathrm{S}} = 1 - 12 / 60 = 0.8$，
随机排序下 $\rho_{\mathrm{S}} \ge 0.8$ 的概率是 $(1 + 3) / 24 \approx 16.7\%$。
所以读论文时，看到"相关系数 0.9"先问是在几个策略上算的；策略数很少时，这个数字的说服力有限。
另外别忘了 $y_i$ 自己也带着第 1.7 节的测量误差，它会进一步拉低能观察到的相关性。

### 6.6 评估器被钻空子

Phase 1 第 8.5 节的结论是：对一个有误差的模型做优化，优化器会专挑误差偏乐观的地方走。
把世界模型当评估器用时，这个问题以三种形式出现，从轻到重：

**形式一：偏差和策略相关（没有人在优化，但偏差不公平）。** 世界模型在演示数据覆盖的状态附近最准。
于是：

- 行为接近演示的策略，在模型里的表现接近真实。
- 走到数据之外的策略，模型只能外推。外推的方向取决于模型的先验。

视频世界模型有一种很有代表性的外推方式：**训练数据大多是成功的演示，所以不管给它什么动作，它都倾向于画出成功的结局**。
夹爪明明偏了两厘米，生成的画面里物体还是"吸"进了夹爪。这相当于模型对动作不够敏感，退回到了"通常会发生什么"的先验。
结果是差的策略被高估，模型里的成功率挤在高处分不开（世界模型甲的"压缩"是它的温和版本）。
相反的情形也有：一个比演示者更好、行为新颖的策略去了数据里没有的地方，画面在那里崩坏，
成功判定器判它失败（世界模型丁）。缓解这一类问题的共同办法是让世界模型的训练数据里**包含失败的回合和多种水平的策略的数据**。

**形式二：用评估结果做选择（你在优化）。** 从 10 个检查点里挑模型里成功率最高的那个，就是一次 $\max$ 操作。
对带噪声的估计取最大值会系统性地高估，这在 Phase 1 第 8.5 节和 Phase 4 的 Q-learning 过估计里见过。

手算一下量级。10 个检查点的真实成功率都是 0.5，各评估 20 个回合，标准误差 0.112（第 1.7 节）。
10 个独立标准正态变量的最大值，期望约为 1.54。所以被选中的那个检查点，测得的成功率的期望约为

$$
0.5 + 1.54 \times 0.112 \approx 0.67
$$

它看上去比别人好 17 个点，实际上一点都不好。这个现象在真机评估里同样存在，但两者有一个关键区别：
真机评估的误差是纯采样噪声，多跑回合就会缩小；世界模型的误差里有**系统性**的部分，
同一个检查点在模型里跑一万个回合，得到的还是同一个带偏差的数。在模型里多跑回合只能消除采样噪声，消除不了模型偏差。

**形式三：在评估器里训练策略（优化器在全力钻空子）。** 一旦把世界模型里的成功信号当作训练目标
（在世界模型里做强化学习、或者按模型里的成败筛选数据再训练），策略会主动寻找模型的漏洞，
这就完整回到了 Phase 1 的模型被钻空子和 Phase 2 "在梦里学会作弊"的故事。第 7、8 节继续讨论。

**怎么办。**

| 办法 | 做什么 | 针对哪种形式 |
| --- | --- | --- |
| 先做相关性验证 | 拿一批已有真实成功率的策略，在世界模型里评估，计算第 6.4 节的三个指标。通过了再用它评估新策略 | 全部。这是使用任何替代评估器的前提 |
| 留出策略 | 验证相关性的策略里，要有训练世界模型时没用过其数据的策略 | 形式一 |
| 训练数据包含失败 | 用多种水平的策略采数据来训练世界模型 | 形式一的"幻觉成功" |
| 缩短展开，分段评估 | 把长任务切成几段，每段从真实画面重新开始 | 第 6.3 节的累积误差 |
| 单独检验成功判定器 | 在真实视频上测判定器的准确率；人工抽查它在生成视频上的判定 | 判定器的错误 |
| 选择用模型，定论用真机 | 用世界模型筛掉明显差的候选，最后的少数几个仍然上真机 | 形式二 |
| 评估器独立于被评估者 | 不用和策略共享骨干、共享训练数据的世界模型来给这个策略打分 | 第 5.4 节的"自己评估自己" |
| 用不确定性把关 | 集成或其他不确定性估计（Phase 1 第 8 节），对分歧大的回合不下结论 | 形式一 |

### 6.8 算法

```
算法：在世界模型里评估一个策略

输入：策略 π，世界模型 p_θ，成功判定器 g，n 个真实初始画面，回合最大长度 T
对每个初始画面 o_0（可以并行）：
 1. 历史 ← [o_0]
 2. 重复直到满 T 步：
        A ← π(历史里最近 T_o 帧)                          动作块 [K, D_a]
        对 A 的前 T_a 个动作逐个：
            ô ← 世界模型根据历史和这个动作生成下一帧         [C, H, W]
            把 ô 追加到历史
 3. success ← g(历史)                                    0 或 1
输出：ŷ = success 的平均值；以及第 1.7 节的置信区间
```

```
算法：检验世界模型能不能当评估器

输入：N 个策略，各自的真实成功率 y_1 … y_N
 1. 对每个策略运行上面的算法，得到 ŷ_1 … ŷ_N
 2. 计算 Pearson：两组数去均值后的内积，除以各自长度的乘积
 3. 计算 Spearman：两组数各自换成名次（并列取平均名次），再算 Pearson
 4. 计算 MMRV：
        对每一对 (i, j)：若 (ŷ_i < ŷ_j) 与 (y_i < y_j) 不一致，RV[i, j] = |y_i − y_j|，否则为 0
        MMRV = 对 i 取平均( 对 j 取最大( RV[i, j] ) )
 5. 画散点图：横轴真实成功率，纵轴模型里的成功率，每个策略一个点，带各自的置信区间
```

第 5 步不要省。三个数字是摘要，散点图才看得出问题出在哪个策略上（世界模型丁那样的情形一眼就能看出来）。

### 6.10 常见误区

- **误区：世界模型生成的视频看起来很真，所以它是个好的评估器。**
  实际情况：画面质量（开环指标）和评估可信度（闭环的排序一致性）是两回事。
  画面再真，如果对动作不敏感、总是画出成功的结局，它给所有策略的分数都差不多，没有区分能力。
- **误区：好的评估器应该让模型里的成功率等于真实成功率。**
  实际情况：第 6.3 节说明这在长回合上几乎做不到，第 6.5 节的世界模型乙说明这也不必要。要的是排序一致。
- **误区：相关系数高就可以放心用。**
  实际情况：先看是在几个策略上算的、这些策略的水平是否拉得开、有没有留出的策略。
  5 个策略里放一个成功率为 0 的随机策略，相关系数很容易就高了。
- **误区：在世界模型里多跑一些回合，结果就更准。**
  实际情况：多跑回合只减小采样噪声。模型的系统性偏差不随回合数减小。
- **误区：相关性验证通过一次，这个世界模型以后就可以一直用。**
  实际情况：验证只对"和验证时相似的策略"有效。换了一类新的策略（新架构、新的动作表示、明显更强），
  它可能去到模型没见过的状态，需要重新抽查。

## 7. 把世界模型当数据引擎

### 7.1 直觉

机器人学习最缺的是数据。图像分类里对付数据少的老办法是数据增强：把一张图裁剪、翻转、调色，一张变十张。
数据引擎是同一个想法在"轨迹"上的版本：手上有一个能生成机器人视频的世界模型，
让它从真实的起始画面出发，按不同的指令生成新的轨迹，把一份演示变成很多份，甚至生成演示里从没出现过的行为。

你在 LLM 课里见过它的文本版：用一个大模型生成合成数据，再拿来训练小模型。
两边的好处和风险是一样的。好处是数据量几乎不受限；风险是**学生会把老师的毛病当成知识学进去**，
而且老师的输出没有标准答案可以对照，毛病不容易被发现。

在本课程里，这也不是新东西。Phase 4 的 Dyna、Phase 5 的 MBPO 做的就是"用模型生成数据来训练策略"。
数据引擎是它们在模仿学习设定下的版本，Phase 5 学到的那条教训（模型生成的数据要短、要掺着真实数据用）在这里原样适用。

### 7.2 定义

以 DreamGen（Jang et al. 2025，arXiv:2505.12705）为代表，数据引擎的流水线分四步：

```
   ① 微调视频世界模型                ② 生成"神经轨迹"的画面
   ┌─────────────────────┐          ┌──────────────────────────────┐
   │ 预训练的视频生成模型    │          │ 输入：真实的起始画面 + 语言指令  │
   │   + 目标机器人的        │ ───────▶ │ 输出：一段机器人完成该指令的视频 │
   │     少量遥操作数据      │          │ （可以是演示里没有的新行为、新环境）│
   └─────────────────────┘          └──────────────┬───────────────┘
                                                   │ 只有画面，没有动作
                                                   ▼
   ④ 训练策略                        ③ 打伪动作标签
   ┌─────────────────────┐          ┌──────────────────────────────┐
   │ 真实演示 + 神经轨迹     │ ◀─────── │ 逆动力学模型（第 4 节）         │
   │ 一起训练视觉运动策略    │          │ 或 隐动作模型（Phase 9）        │
   └─────────────────────┘          └──────────────────────────────┘
```

论文把第 ② 步生成、第 ③ 步打上伪动作标签之后的数据叫做**神经轨迹**（neural trajectories）。
摘要报告的主要结果是：只用一个环境里一种抓放任务的遥操作数据，配合生成的神经轨迹，
让人形机器人在见过和没见过的环境里完成了 22 种新行为。论文同时提出了一个评测视频生成模型的基准 DreamGen Bench。

数据引擎可以按"生成的数据新在哪里"分成三类：

| 类型 | 生成什么 | 动作从哪来 | 难度与风险 |
| --- | --- | --- | --- |
| 换外观 | 同一条轨迹，换背景、光照、物体纹理 | 沿用原轨迹的动作 | 最安全：动作是真实的，只是画面被改了。风险是改画面时把任务相关的东西也改了 |
| 换行为 | 从真实起始画面出发，按新的语言指令生成新的动作过程 | 逆动力学或隐动作模型打伪标签 | DreamGen 属于这一类。画面和动作都是模型产物，两处都可能错 |
| 换动作（反事实） | 从真实状态出发，给定一段和演示不同的动作，生成"如果这样做会怎样" | 给定的动作本身 | 需要动作条件的世界模型。最接近 MBPO 的做法 |

和 MBPO 对照：

| | MBPO（Phase 5） | 数据引擎（本节） |
| --- | --- | --- |
| 策略怎么学 | 强化学习（SAC），需要奖励 | 模仿学习，不需要奖励 |
| 世界模型 | 状态空间的概率集成，以动作为条件 | 像素空间的视频生成模型，通常以语言为条件 |
| 生成的起点 | 回放缓冲区里的真实状态 | 真实的起始画面 |
| 生成多长 | 很短（Phase 5 讲过为什么） | 整段任务，几秒到几十秒 |
| 动作从哪来 | 当前策略给出（先有动作，后有结果） | 事后由逆动力学推断（先有结果，后有动作） |
| 怎么防模型出错 | 短展开；集成；真实数据与生成数据按比例混合 | 过滤；真实数据与生成数据混合；目前没有同样成熟的理论 |

最后两行是要害。MBPO 用短展开把模型误差压住；数据引擎一次生成整段任务，
正好站在 Phase 1 第 5 节和本章第 6.3 节说的"误差随步数累积"的不利一侧。

### 7.3 推导：有偏的数据什么时候值得加

生成的数据不是免费的午餐，它带着模型的偏差。加还是不加，可以用一个极简的模型算清楚。

**设定。** 要估计一个量 $\mu$（可以理解成"某个情境下正确的动作"的一个分量）。

- 真实样本：均值 $\mu$，方差 $\sigma^2$，共 $n_r$ 个。无偏但少。
- 生成样本：均值 $\mu + b$，方差 $\sigma^2$，共 $n_g$ 个。$b$ 是生成数据的系统性偏差
  （世界模型的物理错误加上伪动作标签的错误），数量可以很多。
- 做法：把两种样本混在一起，取所有 $n_r + n_g$ 个样本的平均值作为估计（相当于在混合数据上等权重地训练）。

**第一步：混合估计的偏差。** 期望的线性性质：

$$
\mathbb{E}[\hat\mu_{\text{mix}}] = \frac{n_r \mu + n_g (\mu + b)}{n_r + n_g} = \mu + \frac{n_g}{n_r + n_g} \, b
$$

偏差是 $\frac{n_g}{n_r + n_g} b$：生成数据占多大比例，就带进来多大比例的偏差。

**第二步：混合估计的方差。** $n_r + n_g$ 个独立样本的平均值（第 1.7 节同样的一步）：

$$
\mathrm{Var}[\hat\mu_{\text{mix}}] = \frac{\sigma^2}{n_r + n_g}
$$

**第三步：均方误差 = 偏差的平方 + 方差。**

$$
\mathrm{MSE}_{\text{mix}} = \Big( \frac{n_g}{n_r + n_g} \Big)^2 b^2 + \frac{\sigma^2}{n_r + n_g}, \qquad \mathrm{MSE}_{\text{real}} = \frac{\sigma^2}{n_r}
$$

**第四步：什么时候混合更好。** 令 $\mathrm{MSE}_{\text{mix}} < \mathrm{MSE}_{\text{real}}$，把方差项移到右边并通分：

$$
\Big( \frac{n_g}{n_r + n_g} \Big)^2 b^2 < \frac{\sigma^2}{n_r} - \frac{\sigma^2}{n_r + n_g} = \frac{\sigma^2 \, n_g}{n_r (n_r + n_g)}
$$

两边同乘 $(n_r + n_g)^2 / n_g^2$：

$$
b^2 < \frac{\sigma^2 (n_r + n_g)}{n_r \, n_g} = \sigma^2 \Big( \frac{1}{n_r} + \frac{1}{n_g} \Big)
$$

**读这个条件。** 右边在 $n_g$ 很大时约等于 $\sigma^2 / n_r$，也就是"只用真实数据时的估计方差"。
所以条件说的是：**生成数据的偏差（平方）必须小于真实数据因为太少而带来的不确定性。**

- 真实数据很少（$n_r$ 小）：右边大，容得下相当大的偏差。生成数据有帮助。
- 真实数据多起来（$n_r$ 大）：右边变小，同样的生成数据从帮忙变成拖累。
- 真实数据为零的新行为（$n_r \to 0$）：右边趋于无穷。有偏的数据总比没有数据强。
  这对应 DreamGen 最引人注目的用法：生成演示里完全没有的行为。

**手算例子。** 取 $\sigma = 0.5$（$\sigma^2 = 0.25$），偏差 $b = 0.1$，生成数据是真实数据的 9 倍。

| | $n_r$ | $n_g$ | 偏差平方 $(0.9 \times 0.1)^2$ | 方差 $0.25 / (n_r + n_g)$ | 混合的 MSE | 只用真实数据的 MSE $0.25 / n_r$ | 结论 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 数据少 | 10 | 90 | 0.0081 | 0.0025 | 0.0106 | 0.0250 | 混合更好，误差降到约四成 |
| 数据多 | 100 | 900 | 0.0081 | 0.00025 | 0.00835 | 0.0025 | 混合更差，误差是三倍多 |

用条件验算第二行：$b^2 = 0.01$，右边 $0.25 \times (1/100 + 1/900) = 0.0028$，$0.01 > 0.0028$，不满足，和表里一致。

这个模型当然过于简化（真实的策略学习不是估计一个均值，生成数据的偏差也不是一个常数），
但它给出的定性结论是可靠的工程直觉：**生成数据的价值随真实数据的增多而下降；偏差不会因为生成得更多而消失。**
它还提示了两个实用的旋钮：降低生成数据的占比或权重（减小第一步里的比例），以及过滤掉偏差大的样本（减小 $b$）。

### 7.4 数据引擎里的"钻空子"

当仿真器用时，世界模型的错误会让你**看错**；当数据引擎用时，世界模型的错误会被策略**学进去**。
按流水线的四步逐一看错误从哪来：

| 环节 | 会出什么错 | 策略学到什么 |
| --- | --- | --- |
| ② 生成画面 | 物体穿模、凭空出现或消失；夹爪没碰到物体，物体却跟着走；机械臂的长度和形状在变 | 不需要真的抓稳，"差不多到位"就行，因为在生成的数据里这样做确实成功了 |
| ② 指令跟随 | 让它"拿起杯子"，它生成的是"碰了一下杯子" | 指令和行为的对应关系被污染 |
| ③ 伪动作标签 | 逆动力学模型在生成帧上是分布外输入；接触时刻动作不可辨识（第 4.4 节） | 关键时刻的动作是错的或者是平均出来的 |
| ④ 混合训练 | 生成数据量远大于真实数据，把真实数据淹没 | 偏差按占比进入策略（第 7.3 节第一步） |

这里没有一个显式的优化器在对着模型求最大值，为什么还叫"钻空子"？因为流水线里藏着两处**选择**：

1. **过滤是一次选择。** 生成的轨迹通常要过一遍筛子，只留下"看起来成功了"的。
   筛子（成功分类器或视觉语言模型）有误判，生成器有漏洞，筛选出来的恰恰富集了"生成器出错且筛子没发现"的样本。
   这和 Phase 1 第 8.5 节是同一个机制：对带噪声的分数做选择，选出来的样本系统性地偏向噪声有利的一侧。
2. **迭代是一个循环。** 策略用生成数据训练，策略采的数据再去微调世界模型，世界模型再生成数据。
   如果每一圈都不掺入足够的真实数据，错误会被一圈圈放大。Phase 1 第 9.4 节的闭环能自我纠错，
   靠的是每一圈都有**真实环境**的反馈把漏洞补上；数据引擎的循环如果只在模型内部转，就没有这个纠错来源。

缓解的办法，多数是把 MBPO 的经验搬过来：

| 办法 | 做法 | 对应的 MBPO 经验 |
| --- | --- | --- |
| 锚定真实起点 | 每条生成的轨迹都从一帧真实画面开始 | 从回放缓冲区的真实状态出发做分支展开 |
| 生成得短 | 把长任务拆成短片段分别生成 | 短展开 |
| 保持真实数据的比例 | 每个批次里固定一部分真实演示 | 真实数据与模型数据按比例混合 |
| 一致性过滤 | 用伪动作在动作条件的世界模型里重新生成一遍，和原视频对不上的丢掉；逆动力学模型不确定的片段丢掉 | 集成分歧大的样本不可信 |
| 评估不用同一个模型 | 用生成数据训练的策略，不能再用同一个世界模型来评估 | 最终性能看真实环境 |
| 先评测生成器 | 在使用之前，先评估视频模型的指令跟随和物理合理性 | 先验证模型的多步预测再拿去用 |

DreamGen Bench 做的是最后一行：给视频生成模型打"指令跟随"和"物理合理性"两类分，
论文报告这个基准的分数与下游策略的表现相关（待核对：具体的相关程度）。
这其实是第 6 节的思路换了一个对象：用一个便宜的代理指标预测昂贵的真实结果，而代理指标可不可信，还是要靠相关性来验证。

```

```

### 7.7 常见误区

- **误区：生成的数据越多越好。**
  实际情况：方差随数据量下降，偏差不会。第 7.3 节的条件里，$n_g$ 再大，右边也只是趋近 $\sigma^2 / n_r$。
  生成数据的质量（$b$）比数量重要。
- **误区：过滤之后留下的都是好数据。**
  实际情况：过滤本身是一次带噪声的选择，会富集"生成器出错而过滤器没看出来"的样本。过滤器也需要单独检验。
- **误区：用生成数据训练出来的策略，可以在同一个世界模型里评估。**
  实际情况：策略学到的正是这个模型的世界观，在这个模型里它当然表现好。这是最直接的自己评估自己。
- **误区：数据引擎能凭空创造信息。**
  实际情况：它的信息有两个来源：视频模型预训练时见过的海量视频（物理和物体的先验），和少量真机数据（这台机器人的样子）。
  它做的是把前者迁移过来，迁移的质量受视频模型和逆动力学模型两头限制。

## 8. 真机上的世界模型

### 8.1 直觉

到目前为止，本章的世界模型都是用**别人采好的数据**离线训练的：遥操作演示，或者互联网视频。
Phase 6 的 Dreamer 是另一种工作方式：智能体自己和环境交互，边采数据、边学世界模型、边在想象里改进策略。
把这个循环原样搬到真实机器人上会怎样？

对工程师来说，这相当于**没有预发布环境，直接在生产环境里边跑边训练，而且线上流量不能暂停**。
仿真里 `env.step()` 会等你算完；真机不等。仿真里摔了重置就行；真机摔了要人去扶，或者得自己学会爬起来。
这带来的不是算法上的新问题，而是一组工程约束：延迟、控制频率、安全、没有重置、奖励从哪来。

本节讲两个代表性的工作，它们恰好是世界模型两种用法在真机上的落地：
**DayDreamer** 是"在想象中学习"（Phase 6），**V-JEPA 2-AC** 是"决策时规划"（Phase 1、Phase 10）。

### 8.2 定义：两种真机范式

**DayDreamer**（Wu et al. 2022，arXiv:2206.14176）把 Dreamer 直接用在真实机器人上，不经过任何仿真器。
摘要给出的结果：一个四足机器人从零开始、在没有人工重置的情况下，只用 1 小时学会了翻身、站起来和行走；
之后研究者去推它，它在 10 分钟内学会了抵抗推搡或者快速翻回来站好。
在两种机械臂上，它直接从相机图像和稀疏奖励学会了抓取并放置物体；在一个轮式机器人上学会了导航到目标位置。
论文在全部机器人上使用同一套超参数。

它的算法和 Phase 6 相同，新东西在系统结构上：**采集数据的线程和训练的线程分开，各跑各的**。

```
   ┌────────────────────────────┐                  ┌────────────────────────────────┐
   │  Actor 线程（跟着机器人的节拍）│                  │  Learner 线程（跟着 GPU 的节拍）   │
   │                            │   经验            │                                │
   │  读传感器 ──▶ 编码 ──▶ 策略   │ ───────────────▶ │  回放缓冲区                      │
   │      ▲            │        │                  │     │                          │
   │      │            ▼        │                  │     ▼                          │
   │   机器人 ◀── 执行动作        │                  │  训练世界模型（RSSM）             │
   │                            │   最新的参数       │     │                          │
   │  每个控制周期必须按时给出动作  │ ◀─────────────── │     ▼                          │
   │                            │                  │  在想象里训练 actor 和 critic     │
   └────────────────────────────┘                  └────────────────────────────────┘
```

分开的原因：机器人的控制周期是固定的（几十毫秒），而一次梯度更新的耗时不固定，也没必要和控制周期对齐。
分开之后，机器人这边永远按时出动作；训练那边 GPU 有多快就跑多快，机器人每走一步，
学习线程可以在想象里训练很多步。这就是世界模型在真机上样本效率高的直接来源：
**真实交互很慢，想象很快，把两者解耦之后，慢的那一边不再是瓶颈。**

**V-JEPA 2-AC**（Assran et al. 2025，arXiv:2506.09985）走的是另一条路，Phase 10 已经讲过它的模型部分，这里只回顾它在真机上怎么用。
摘要给出的做法：编码器在超过 100 万小时的互联网视频上自监督预训练，然后冻结；
再用不到 62 小时的无标注机器人视频（来自 Droid 数据集；"无标注"指没有任务标签和奖励，机器人的动作信息是用到的）训练一个动作条件的预测器；
把它零样本地部署到两个不同实验室的机械臂上，用**目标图像**指定任务，靠规划完成抓取和放置，
过程中不在这些机器人的环境里采集任何数据，没有任务相关的训练，也没有奖励。

规划的方式就是 Phase 1 的 CEM 加滚动时域，搬到了表征空间：

```
   当前画面 ──▶ 冻结的编码器 ──▶ 当前表征 ─┐
                                         ├──▶ 动作条件预测器 ──▶ 预测的未来表征 ──┐
   CEM 采样的候选动作序列 ─────────────────┘                                      ├──▶ 距离 = 代价
                                                                                │
   目标图像 ──▶ 冻结的编码器 ──▶ 目标表征 ────────────────────────────────────────┘

   CEM 迭代若干轮，取代价最低的动作序列，执行第一个动作，重新规划
```

两种范式并排比较：

| | DayDreamer | V-JEPA 2-AC |
| --- | --- | --- |
| 世界模型的用法 | 在想象中训练策略（Phase 6） | 决策时规划（Phase 1、10） |
| 世界模型的数据 | 这台机器人自己在线采集的 | 互联网视频预训练 + 别处采好的机器人数据，离线 |
| 是否重建像素 | 重建（RSSM 带解码器） | 不重建，在表征空间预测 |
| 任务怎么指定 | 奖励函数 | 目标图像 |
| 在目标机器人上要采数据吗 | 要（四足实验约一小时） | 不要（零样本） |
| 部署时的计算 | 轻：策略网络一次前向 | 重：每一步都要做采样式规划 |
| 能适应环境变化吗 | 能，一直在学 | 模型是固定的；靠重新规划应对扰动 |
| 主要限制 | 需要能自动计算的奖励；探索阶段的安全 | 需要目标图像；规划慢；长时程任务要给中间子目标；对相机位置敏感（论文的局限性讨论，待核对） |

**奖励从哪来。** 仿真环境的奖励是一行代码，真机上它是个实际的工程问题。常见的来源：

| 来源 | 例子 | 特点 |
| --- | --- | --- |
| 本体传感器 | 用惯性测量单元（IMU）判断机身是否直立；关节速度 | 可靠、便宜，但只能表达和机器人自身姿态有关的目标 |
| 额外的仪器 | 夹爪上的接触传感器；物体上的标记点；称重台 | 可靠，但每个任务都要专门搭 |
| 学出来的判定器 | 在成功 / 失败的图像上训练的分类器；视觉语言模型 | 通用，但会判错，而且策略会学着去骗它（又是钻空子） |
| 目标图像 | 给一张"完成后应该是什么样"的图 | 不需要奖励工程，但"表征空间里离目标近"不总是等于"任务完成了" |

### 8.3 推导：延迟的算账

真机上最容易被忽视的约束是时间。第 2.5 节算过"推理可以用多久"，这里把延迟的后果算完整。

**设定。** 控制周期 $\Delta t$。策略在时刻 $t$ 拍下画面，经过 $\delta_{\text{inf}}$（图像采集 + 网络推理 + 通信）之后，
动作块才可以开始执行。动作块有 $k$ 步，是按"从时刻 $t$ 开始执行"来预测的。

**第一步：过期的动作数。** 等动作块算出来时，时间已经过去了 $\delta_{\text{inf}}$，对应的控制步数是

$$
d = \Big\lceil \frac{\delta_{\text{inf}}}{\Delta t} \Big\rceil
$$

块里最前面的 $d$ 个动作是给"已经过去的时刻"准备的。

**第二步：两种执行方式。**

```
   同步执行：算的时候机器人停着等
   ──▶ 时间
   [ 推理 δ ][ 执行 T_a 步 ][ 推理 δ ][ 执行 T_a 步 ] …        机器人走走停停

   异步执行：算的时候机器人继续执行上一个块
   块 1：       [× × × ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓]                    × = 过期的 d 步，丢弃
   块 2：                  [× × × ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓]          ✓ = 可以执行的部分
                ↑ 拍照      ↑ 拍照
                └─ T_a 步 ─┘
```

**第三步：异步执行的可行条件。** 丢掉过期的 $d$ 步之后，一个块还剩 $k - d$ 步可用。
在下一个块可用之前，它必须撑满 $T_a$ 步，所以

$$
k - d \ge T_a \quad \Longleftrightarrow \quad k \ge T_a + \Big\lceil \frac{\delta_{\text{inf}}}{\Delta t} \Big\rceil
$$

而要让推理本身来得及在 $T_a$ 步之内完成，还需要 $d \le T_a$。两个条件合起来：$d \le T_a \le k - d$。

**手算例子。** 控制频率 30 Hz（$\Delta t = 1/30$ 秒，约 33.3 毫秒），块长 $k = 16$。

| 推理延迟 $\delta_{\text{inf}}$ | 过期步数 $d$ | 可用步数 $k - d$ | $T_a$ 的可行范围 | 结论 |
| --- | --- | --- | --- | --- |
| 100 毫秒 | $\lceil 3.0 \rceil = 3$ | 13 | 3 到 13 | 宽裕 |
| 200 毫秒 | $\lceil 6.0 \rceil = 6$ | 10 | 6 到 10 | 可行 |
| 300 毫秒 | $\lceil 9.0 \rceil = 9$ | 7 | 无（要求 $9 \le T_a \le 7$） | 不可行：要么加长动作块，要么换更快的模型 |

**第四步：延迟造成的位置误差。** 策略是根据 $\delta_{\text{inf}}$ 之前的画面做的决定。
如果目标物体在以速度 $v$ 运动，等动作生效时它已经移动了

$$
\Delta x = v \cdot \delta_{\text{inf}}
$$

物体速度 0.2 米每秒、延迟 200 毫秒时，$\Delta x = 4$ 厘米，足以让一次抓取落空。
静态场景里这个误差是零，这也是为什么大多数桌面操作的演示任务都是物体静止的。

**延迟对世界模型意味着什么。** 两件事：

1. **模型要把延迟学进去。** 真机数据里记录的 $(o_t, a_t, o_{t+1})$ 中，$o_{t+1}$ 反映的可能是 $a_{t-1}$ 甚至更早的动作的效果。
   这正是第 4.4 节"动作的效果有延迟"那一行。实用的办法是把最近几步的动作也作为模型的输入，让它自己对齐。
2. **规划的预算是硬的。** Phase 1 第 6.5 节算过决策时规划的计算量。在真机上，
   这笔账直接决定了能用多大的模型、多少候选、几轮迭代。这是决策时规划在真机上的主要障碍，
   也是 DayDreamer 那样"提前把策略训练好"的做法在部署时的优势。

### 8.4 安全

仿真里的探索没有代价，真机上有。常见的防护是分层的，没有哪一层来自学习算法本身：

| 层 | 措施 |
| --- | --- |
| 硬件 | 急停按钮；力矩和电流限制；软的夹爪；隔离的工作区 |
| 底层控制 | 关节限位；速度和加速度限幅；碰撞检测后停机 |
| 动作接口 | 把策略输出裁剪到安全范围；限制末端的工作空间；增量动作限制每步的最大位移 |
| 学习过程 | 从小幅度的动作开始；人在回路中监督，随时接管 |
| 世界模型（研究中） | 执行前先在模型里预演，预测到危险就拒绝执行；用不确定性估计避开模型没把握的动作 |

最后一行是世界模型在安全上的潜在贡献，也是它的风险所在：
用一个会出错的模型来把关，模型在盲区里说"安全"的时候恰恰最危险（Phase 1 第 8.1 节）。
目前这一层只能作为前面几层的补充，不能替代它们。

### 8.5 仿真到真实的差距与评估方法学

真机数据贵，所以人们一直想用别的东西代替它。有三种"替身"，各有各的差距：

| 替身 | 是什么 | 和真实世界的差距在哪 | 缩小差距的办法 |
| --- | --- | --- | --- |
| 物理仿真器 | 人写的刚体物理 + 渲染 | 画面不像（视觉差距）；摩擦、接触、电机响应不像（动力学与控制差距）；柔性物体、液体很难仿 | 域随机化（训练时随机扰动仿真参数）；系统辨识（用真实数据拟合仿真参数）；真实到仿真的场景重建 |
| 学到的世界模型 | 从真实数据学出来的生成模型 | 画面天然像；但没有物理定律兜底，长时程漂移，数据之外会幻觉 | 更多样的数据（含失败）；短展开；不确定性；第 6 节的相关性验证 |
| 另一台真机 / 另一个实验室 | 同型号的机器人，不同的场地 | 相机位置、光照、桌面、物体批次、硬件磨损 | 标准化评估场景；多地重复 |

"仿真到真实的差距"（sim-to-real gap）通常指第一行。它在足式运动上已经被比较好地解决了（大规模并行仿真 + 域随机化），
在接触丰富的操作任务上仍然是难题。第二行可以叫"模型到真实的差距"，性质不同：
物理仿真器的错误是**系统性的、可解释的**（摩擦系数不对），世界模型的错误是**依赖数据分布的、难以预料的**（这个角度没见过）。

这三种替身和真机评估，都要面对同一套方法学问题。读论文或自己做实验时可以按这张清单检查：

| 问题 | 为什么重要 |
| --- | --- |
| 每个策略跑了多少个回合？有没有置信区间？ | 第 1.7 节：20 个回合时区间是正负 22 个点 |
| 初始条件怎么定的？各个策略用的是同一组吗？ | 物体摆放位置的差别可以比方法之间的差别还大 |
| 成功的标准是事先写好的吗？谁来判？判的人知道在评哪个方法吗？ | 事后定标准和知情的评判者都会引入偏向 |
| 有没有报告失败是怎么失败的？ | 成功率是一个标量，看不出两个策略是否败在同一个地方 |
| 评估环境和训练环境差多远？ | "在训练场景里成功"和"换了桌布还成功"是两种能力 |
| 用了替代评估器的话：在几个策略上验证过相关性？三个指标是多少？ | 第 6 节 |
| 被比较的方法调参的力度一样吗？ | 新方法调了一百次、基线只跑了默认配置，是最常见的不公平 |

这张清单的系统展开（随机种子、置信区间、怎么报告）是 Phase 12 的内容。

### 8.6 算法

```
算法：DayDreamer 式的异步真机学习

Actor 线程（按控制周期 Δt 循环）：
 1. 读取传感器，得到 o_t
 2. 用当前的世界模型更新隐状态；用当前的策略采样动作 a_t（经过安全限幅）
 3. 发送动作；把 (o_t, a_t, r_t) 写入回放缓冲区
 4. 每隔一段时间，从 Learner 拉取最新的参数

Learner 线程（不停循环，与控制周期无关）：
 1. 从回放缓冲区采样序列                                    [B, T, …]
 2. 更新世界模型（Phase 6 的世界模型损失）
 3. 从采样序列的后验状态出发，在隐空间里想象 H 步              [B × T, H, D]
 4. 用想象的轨迹更新 actor 和 critic（Phase 6）
```

```
算法：目标图像条件的表征空间规划（V-JEPA 2-AC 式）

输入：目标图像 o_g，冻结的编码器 E，动作条件预测器 P，CEM 参数
 z_g ← E(o_g)
每个控制步：
 1. z ← E(当前画面)
 2. CEM：重复 I 轮
        采样 N 条动作序列                                   [N, H, D_a]
        用 P 从 z 出发展开，得到每条序列末端的预测表征 ẑ_H     [N, D_z]
        代价 = ẑ_H 与 z_g 的距离                            [N]
        用代价最低的 K 条重新估计采样分布
 3. 执行最优序列的第一个动作，回到第 1 步
```

第二个算法和 Phase 1 第 7.8 节的 CEM 伪代码几乎逐行相同，变的只是"状态"换成了表征、"奖励"换成了到目标的负距离。
这是"同一个规划器"这条线索在全课里的最后一次出现。

### 8.8 常见误区

- **误区：真机上学习慢，是因为算法的样本效率不够。**
  实际情况：样本效率只是一半。另一半是重置、奖励、安全这些"非算法"的环节，它们常常占掉大部分时间。
  DayDreamer 的四足实验刻意设计成不需要人工重置。
- **误区：零样本部署说明世界模型已经通用了。**
  实际情况：V-JEPA 2-AC 的零样本是在同类型的机械臂、相似的桌面抓放任务上，用目标图像指定任务。
  换一种机器人、换成长时程任务，都还需要更多的工作。
- **误区：延迟只是让机器人反应慢一点。**
  实际情况：延迟会让动作块的开头过期、让训练数据里动作和结果的对应关系错位、让动态场景里的动作打偏。
  它既是部署问题，也是数据问题。
- **误区：仿真到真实的差距靠更逼真的渲染就能解决。**
  实际情况：画面只是差距的一半。接触、摩擦、电机的响应特性这些动力学上的差距，渲染得再真也没用。

## 9. 其他前沿：自动驾驶与交互式视频

### 9.1 直觉

本章的地图是为桌面操作画的，但它不只适用于机械臂。
换一种"机器人"（一辆车、一个在走廊里走的移动底盘、一个游戏里的角色），四种用法的格子都还在，
只是哪一格最热闹不一样。这一节的目的不是讲新方法，而是练习**用同一张地图给不熟悉的领域的论文归位**。

### 9.2 自动驾驶

自动驾驶和机械臂操作的条件几乎相反，这决定了世界模型在这里主要用在哪：

| | 桌面操作 | 自动驾驶 |
| --- | --- | --- |
| 带动作的数据 | 稀缺，要专门遥操作采集 | 充足：每辆上路的车都在记录画面和方向盘、油门 |
| 动作空间 | 高维，和具体机器人绑定 | 低维（转向、加减速），各车型接近 |
| 真实世界里出错的代价 | 打翻东西 | 人命 |
| 最缺的是什么 | 数据量 | 罕见的危险场景；可靠的闭环评估 |

所以驾驶方向的世界模型，重心在**当仿真器**和**当数据引擎**两格：生成罕见场景来测试和训练规划器。

| 工作 | 做什么 | 落在地图的哪一格 |
| --- | --- | --- |
| GAIA-1（Hu et al. 2023，arXiv:2309.17080） | 把视频、文本、动作都变成 token，用自回归 Transformer 建模，再解码成视频。结构上是 Phase 8 的路线 | 生成式世界模型；数据引擎 / 仿真器 |
| GAIA-2（Russell et al. 2025，arXiv:2503.20523） | 改用隐空间扩散（Phase 9 的路线），支持多相机和更丰富的可控条件 | 同上 |
| Vista（Gao et al. 2024，arXiv:2405.17398） | 强调高保真和多种控制方式的可泛化驾驶世界模型 | 同上；论文还探讨了用模型本身给动作打分 |

从 GAIA-1 到 GAIA-2 骨干从 token 自回归换成隐空间扩散，和本课 Phase 8 到 Phase 9 的顺序一致。

### 9.3 导航

Navigation World Models（Bar et al. 2024，arXiv:2412.03572）训练一个以导航动作为条件的视频扩散模型
（论文称其骨干为 Conditional Diffusion Transformer），数据是人和多种机器人的第一人称视频。
用法是：给定目标图像，采样若干条候选的移动轨迹，用世界模型预测每条轨迹走完后会看到什么，
选预测画面和目标最接近的那条。

这和第 8.2 节 V-JEPA 2-AC 的规划流程是同一个模板，区别只在预测发生在像素空间还是表征空间。
它落在"决策时规划"一格。导航对预测精度的要求比操作低（不涉及精细接触），是生成式世界模型做规划比较容易成立的场景。

### 9.4 交互式视频与通用世界模型

Phase 9 讲过的 Genie 系列、Cosmos、UniSim 走的是"先做一个通用的、可交互的视频世界，再考虑下游用途"的路线。
对机器人来说，它们可能的位置是：

| 可能的用途 | 现状 |
| --- | --- |
| 当数据引擎的基座 | 已经在用：第 7 节的流水线就是在通用视频模型上微调 |
| 当通用的策略评估环境 | 第 6 节的工作在朝这个方向走；相关性验证是门槛 |
| 当训练智能体的环境（在里面做强化学习） | Phase 9 的 Dreamer 4 在游戏里展示了只靠离线数据在世界模型内训练智能体；在真实机器人任务上还是开放问题 |

Genie 2、Genie 3 只有官方博客，没有论文（见 Phase 9 的 README），这里不展开细节。

### 9.5 给一篇新论文归位

读这个方向的新论文时，按顺序问五个问题，基本就能把它放到地图上：

```
   ① 模型的预测以什么为条件？
        只有画面 / 语言 ──▶ 视频生成模型，要另配逆动力学或动作头才能控制机器人
        机器人动作      ──▶ 动作条件的世界模型，可以当仿真器、做规划
        隐动作          ──▶ 能用无标签视频；落地时要映射回真实动作

   ② 预测的是什么？
        像素 / 视频隐表示 ──▶ 生成式（P8、P9）      表征 ──▶ JEPA 式（P10）
        同时预测动作      ──▶ World-Action Model（第 5 节）

   ③ 谁消费模型的输出？
        机器人直接执行    ──▶ 当策略（第 4、5 节）
        做研究的人看分数  ──▶ 当仿真器（第 6 节）
        另一个策略的训练  ──▶ 当数据引擎（第 7 节）或在想象中学习（第 8 节）
        规划器           ──▶ 决策时规划（第 8 节）

   ④ 证据是什么？
        只有生成视频的画面指标         ──▶ 还不能说明对控制有用
        仿真基准上的成功率            ──▶ 看是哪个基准、多少回合
        真机成功率                   ──▶ 看回合数、场景是否见过
        与真实结果的相关性             ──▶ 看在几个策略上算的

   ⑤ 模型的错误会被谁放大？
        有没有对模型的输出做选择、过滤或优化？有的话，怎么防止钻空子？
```

### 9.7 常见误区

- **误区：自动驾驶的世界模型和机器人的世界模型是两个领域，方法不通用。**
  实际情况：骨干、训练目标、评估的方法学都相通。区别在数据条件和最缺的东西不同，所以重心落在地图的不同格子上。
- **误区：能实时交互的视频模型就可以直接当机器人的仿真器。**
  实际情况：还差两件事。它的动作接口要能接上真实机器人的动作（而不是键盘或隐动作），
  而且要通过第 6 节的相关性验证。"看起来可以玩"和"评估结论可信"是两个标准。
- **误区：生成的驾驶视频越逼真，用它测试出来的规划器越安全。**
  实际情况：和第 6.10 节相同。要紧的是模型对规划器的动作是否有正确的反应，尤其是在危险的、数据里少见的情形下。

## 10. 方法对比与选型

### 10.1 四种用法怎么选

| 你的处境 | 优先考虑的用法 | 理由 | 先确认什么 |
| --- | --- | --- | --- |
| 有几十条演示，想要一个能用的策略 | 先不用世界模型：Diffusion Policy 或 ACT | 最短路径；是后面所有方案的基线 | 原样重放演示能否成功（第 2.7 节） |
| 演示很少，但有大量相关的无动作视频 | 当策略（视频预训练 / World-Action Model） | 视频里的运动先验可以迁移 | 逆动力学在目标场景上是否可辨识（第 4 节） |
| 策略迭代得很快，真机评估跟不上 | 当仿真器 | 评估是瓶颈时，替代评估器的收益最大 | 在已有真实结果的策略上做相关性验证（第 6 节） |
| 要覆盖演示里没有的行为或环境 | 当数据引擎 | 真实数据为零时，有偏的数据也有价值（第 7.3 节） | 生成器的指令跟随与物理合理性；最终必须真机评估 |
| 能定义奖励，机器人可以自己长时间运行 | 真机在线学习（Dreamer 式） | 样本效率高，能持续适应 | 奖励能否自动计算；重置与安全 |
| 任务可以用一张目标图像表达，不想采任务数据 | 决策时规划（V-JEPA 2-AC 式） | 零样本；换目标不用重新训练 | 规划耗时能否满足控制频率 |

### 10.2 "当策略"这条线上的四种结构

| | 纯策略（Diffusion Policy、ACT） | 两阶段（UniPi） | 共享骨干（GR-1、VPP） | 联合分布（UVA、UWM） |
| --- | --- | --- | --- | --- |
| 训练时预测未来画面吗 | 不 | 预测，由单独的视频模型 | 预测，作为预训练或辅助任务 | 预测，与动作联合建模 |

### 10.4 收官：PushT 上三类世界模型的总对比

PushT 这条线索从 Phase 8 开始，到这里收束。
三章各自在 PushT 上训练了一类世界模型，本章的讲义和项目把它们放到同一套测试下。先看设计上的差别（这些是确定的事实）：

| | Token 世界模型（Phase 8） | 扩散世界模型（Phase 9） | JEPA 世界模型（Phase 10） |
| --- | --- | --- | --- |
| 画面怎么表示 | 离散 token（VQ-VAE / FSQ） | 连续的像素或隐表示 | 冻结的预训练视觉特征 |
| 训练目标 | 下一个 token 的交叉熵 | 去噪 / flow matching | 表征空间里的预测误差 |
| 能生成画面吗 | 能（经 tokenizer 的解码器） | 能 | 不能（没有解码器） |
| 预测一步的计算 | 每帧若干个 token，自回归逐个生成（或并行解码若干轮） | 若干步去噪 | 预测器一次前向 |
| 随机性怎么表达 | 对 token 的分布采样 | 扩散采样 | 通常是确定性预测 |
| 多步展开的典型问题 | token 采样误差累积；细节受 tokenizer 限制 | 自回归漂移 | 表征空间里的漂移看不见，要靠探针检查 |
| 当策略（第 4、5 节） | 可以配逆动力学 | 可以配逆动力学；与扩散策略同构，便于做成联合模型 | 没有画面可供逆动力学使用；需要在表征上训练动作头 |
| 当仿真器（第 6 节） | 可以，成功判定看生成的画面 | 可以，成功判定看生成的画面 | 需要一个从表征读出物体位姿的探针来判定成功 |
| 当数据引擎（第 7 节） | 可以 | 可以 | 不能生成给像素策略用的数据；只能为同样用该表征的策略生成特征序列 |
| 决策时规划（第 8 节） | 可以，但每步很慢 | 可以，但每步更慢 | 最合适：展开便宜，代价直接在表征空间算 |

要让三者能比，必须有一把共同的尺子。像素指标（PSNR 等）对 JEPA 不适用，所以统一用**状态误差**：
从每个模型预测的结果里读出 T 形块的位姿（Token 和扩散模型从生成的画面里读，JEPA 用 Phase 10 的线性探针从表征里读），
和仿真器给出的真实位姿比较。成功判定也统一基于读出的位姿。

实验之前可以先写下定性的预期，实验之后看哪些对、哪些错（这些是预期，不是结果）：

- 开环的位姿误差，三类模型都应随步数增大；谁增长得慢，取决于各自的漂移机制，没有先验的答案。

### 10.5 世界模型路线与 VLA 路线

| | VLA（RT-2、OpenVLA、π0） | 世界模型路线（本章） |

## 12. 实现陷阱与调试清单

| 现象 | 可能的原因 | 怎么排查 | 怎么修 |
| --- | --- | --- | --- |
| 把数据集里的动作原样重放，到不了录像里的终点 | 动作的约定理解错了：绝对 / 增量、坐标系、归一化、控制频率 | 在仿真器里重放一个回合，和录像逐帧对比 | 对照数据集的元数据逐项确认；先解决这个再训练 |
| 训练损失很低，闭环成功率很低 | 分布偏移：损失是在专家的状态上算的，成功率是在策略自己的状态上测的 | 画策略访问的状态与演示状态的距离随时间的变化 | 动作分块；更多样的起始位置；加入纠错演示 |
| 策略在岔路口停住，或者走了两条路的中间 | MSE 行为克隆的均值塌缩 | 画同一观测下演示动作的分布，看是否多峰 | 换成扩散策略或把动作离散化 |
| 动作来回抖动，左右摇摆 | 执行长度 $T_a$ 太小，相邻两次采样选了不同的峰 | 记录相邻两个动作块在重叠时间段上的差异 | 增大 $T_a$；用时间集成；用上一个块引导下一次采样 |
| 机器人动一下停一下 | 同步执行，推理时间超过了一个控制周期 | 给推理计时，和 $T_a \cdot \Delta t$ 比较 | 异步执行；减少去噪步数；换小模型 |
| 加入观测延迟后成功率骤降 | 动作块开头的过期动作被执行了 | 算过期步数 $d$，检查是否 $d \le T_a \le k - d$ | 丢弃前 $d$ 步；加长动作块；训练时把延迟模拟进去 |
| 逆动力学模型验证误差很低，给生成的视频打的标签却很差 | 生成帧对它来说是分布外输入 | 分别统计真实帧对和生成帧对上的动作误差 | 训练时对输入帧加噪声和模糊；在世界模型生成的帧上微调 |
| 逆动力学模型在接触时刻误差明显偏大 | 动作不可辨识（顶住、夹紧、打滑） | 把误差按是否接触分组统计 | 输入加上本体感觉和更多历史帧；输出分布而不是单点；不要指望完全解决 |
| 两阶段策略的动作幅度整体偏大或偏小 | 视频模型的帧间隔与逆动力学模型训练时的帧间隔不一致 | 核对两边的帧率 | 统一帧间隔，或把间隔作为逆动力学模型的输入 |
| 联合训练视频和动作后，动作反而变差 | 视频那一项损失主导了梯度 | 分别监控两项损失和它们的梯度范数 | 调整两项的权重；降低视频的分辨率或 token 数 |
| 世界模型里所有策略的成功率都很高，分不开 | 模型对动作不敏感，总是画出成功的结局 | 喂给它随机动作或全零动作，看是否仍然"成功" | 训练数据里加入失败回合和随机动作；确认动作条件确实起作用 |
| 模型里的成功率与真实成功率相关性低 | 展开太长导致漂移；成功判定器不准 | 缩短展开看相关性是否回升；在真实视频上测判定器的准确率 | 分段评估；改进判定器 |
| 相关系数很高，按模型选出的最优策略却是错的 | 相关系数被一个离群的策略撑起来；策略太少 | 去掉最差的策略重新计算；看散点图；看 MMRV | 增加水平接近的策略；同时报告 MMRV |
| 加入生成数据后策略变差 | 生成数据的偏差超过了它带来的好处；占比过大 | 改变真实 / 生成的比例做对照实验 | 降低占比；加强过滤；只在真实数据最少的行为上用 |
| 用生成数据训练的策略在世界模型里表现很好，真实环境里很差 | 自己评估自己：策略学到的正是这个模型的错误 | 换一个独立的评估环境 | 最终评估必须在真实环境（或独立的评估器）里做 |
| 目标图像规划时代价一直在下降，任务却没完成 | 表征空间里的距离与任务进度不一致 | 用探针从预测的表征里读出物体位姿，看它是否真的在接近目标 | 换用 patch 级特征计算代价；给中间子目标 |

调试顺序的建议：先确认数据（重放），再确认策略在真实环境里的基线，然后单独检验每个学到的部件
（逆动力学模型、世界模型的开环预测、成功判定器），最后才把它们接起来做闭环。
和 Phase 1 第 12 节的原则相同：每接上一个部件之前，先确认它单独是好的。

## 13. 常见问题（FAQ）

### Q1：机器人为什么不直接用强化学习，像前面几章那样？

三个原因：真机上试错又慢又危险；大多数操作任务没有现成的奖励函数；探索初期的随机动作在真机上既低效也伤硬件。
模仿学习用人的演示绕开了这三点。强化学习并没有退出：足式运动普遍在仿真里用强化学习训练再迁移到真机，
操作任务上也有用强化学习微调模仿策略的工作。世界模型是让强化学习回到真机的一条途径（第 8 节），
因为它把大部分试错搬进了想象里。

### Q2：动作分块和 MPC 的滚动时域是什么关系？

结构相同：都是"算出一段、执行前面一部分、再重新算"。区别有两点。
MPC 的那一段是在模型里搜索出来的，动作分块的那一段是策略网络直接输出的；
MPC 通常只执行一步，动作分块执行多步。可以把带分块的策略看成一个"把搜索结果提前蒸馏进网络"的 MPC。
两者面对同样的权衡：执行得越长，计算越省，对意外的反应越慢。

### Q3：Diffusion Policy 和 Phase 9 的扩散世界模型是什么关系？

同一种生成模型用在不同的变量上。扩散世界模型对未来的观测做去噪，条件是历史观测和动作；
Diffusion Policy 对未来的动作做去噪，条件是历史观测。网络结构、训练目标、采样器都可以共用。
正因为同构，才能把两者合进一个网络（第 5 节）。

### Q4：已经有 VLA 了，为什么还需要世界模型？

VLA 是策略，它回答"现在该做什么"。它不能回答"这样做会怎样"，所以评估它、给它造数据、在部署前预演它的行为，
都需要另外的工具。世界模型正是这个工具。另外，VLA 的预训练知识主要来自图文数据，
对"物体怎么运动"的了解有限；从视频里学到的预测能力是一个互补的知识来源。两条路线在合流而不是在竞争（第 10.5 节）。

### Q5：既然逆动力学模型也要带动作的数据，为什么不直接用这些数据学策略？

因为两者对数据的要求不同。策略要学"该做什么"，需要好的演示；逆动力学只学"做了什么"，任何带动作的数据都能用，
包括随机乱动的数据。而且逆动力学是一个更容易的问题：结果已经给定，答案大多唯一，需要的数据量小得多（第 4.6 节的表）。
这条路线的赌注是：把难的那一半（该做什么）交给能从海量视频里学习的视频模型。

### Q6："把视频预测当策略"里的视频模型不接受动作输入，它还算世界模型吗？

按本课程在 Phase 1 第 1.2 节的标准，严格说不算：它不能回答"如果我这样做会怎样"。
它建模的是 $p(o_{t+1} \mid o_t, \ell)$，即"在完成这个指令的过程中，接下来会看到什么"，已经把策略吸收进去了。
第 4.6 节的推导表明，它加上逆动力学模型等价于一个策略；而只有带动作条件的模型才能当仿真器或用于规划。
这就是为什么第 9.5 节归位新论文时，第一个问题就是"预测以什么为条件"。

### Q7：World-Action Model 比"一个世界模型 + 一个策略"两个独立模型好在哪？

三点：共享表征，动作学习能从视频预测借到稠密的监督信号；没有动作标签的视频可以直接参与训练；
一个模型可以按需充当策略、世界模型、逆动力学。代价也有三点：训练更贵；两个目标要权衡；
以及一个隐患：它的世界模型和策略共享错误，不适合用来评估自己（第 5.7 节）。

### Q8：世界模型里的成功率和真实成功率差了二十个点，这个评估器还能用吗？

看这二十个点是不是对所有策略都差不多。如果是，排序不受影响，它仍然是个好评估器（第 6.5 节的世界模型乙）。
应该做的是拿一批已知真实成功率的策略算一遍 Pearson、Spearman 和 MMRV，而不是盯着绝对差距。
反过来，绝对差距很小也不说明问题（世界模型丙）。

### Q9：验证一个评估器，需要多少个策略？

越多越好，而且水平要拉开、类型要多样。第 6.5 节算过：只有 4–5 个策略时，
随机排序碰巧得到很高相关系数的概率并不小。实际能做到的规模受限于真机评估的成本，
所以读论文时要把"在多少个策略、多少个任务上验证的"当作结论的一部分来读。
除了数量，还要看有没有**留出**的策略：其数据没有用于训练世界模型的策略。

### Q10：Pearson、Spearman、MMRV，到底该报告哪个？

都报告，再配一张散点图。它们回答不同的问题：Pearson 问线性关系有多强，Spearman 问排序对了多少，
MMRV 问排错的那些有多要紧。只报告一个容易被钻空子（比如放进一个明显很差的策略来抬高 Pearson）。
如果只能选一个用于"能不能拿它来选模型"的决策，MMRV 最贴近这个目的，因为它直接按真实差距给排序错误定价。

### Q11：数据引擎和普通的数据增强有什么区别？

数据增强改的是画面（裁剪、调色），不改轨迹，动作标签仍然是真实的。
数据引擎可以生成新的轨迹：新的动作过程、新的行为。能力更强，风险也更大，因为画面和动作标签都成了模型的产物。
第 7.2 节表里的"换外观"一类介于两者之间：轨迹是真实的，只有外观是生成的。

### Q12：DayDreamer 一小时就能学会走路，为什么操作任务不都这样做？

走路的奖励可以用机身上的传感器自动算出来，摔倒了可以自己爬起来继续，探索时的随机动作也不太会造成损坏。
操作任务这三条都不太满足：成功与否往往要看物体的状态，物体被碰掉了要人去捡回来，
而且稀疏奖励下的随机探索很难碰巧完成一次抓取。DayDreamer 论文里的机械臂实验用的就是稀疏奖励，
学习时间也比走路长得多（具体时长待核对）。

### Q13：本课程没有真机，本章的结论怎么验证？

用仿真器扮演"真实环境"，用学到的世界模型扮演"仿真器"。这个替换保留了问题的结构：
世界模型相对于仿真器的误差，类似于任何替代评估器相对于真实世界的误差。
它甚至有一个好处：仿真器里可以跑成千上万个回合，把"真实成功率"的测量噪声压到很低，
从而把世界模型自身的误差单独分离出来研究。它缺失的是真机特有的麻烦：硬件噪声、延迟、标定误差，
第 8 节的讲义用人为注入延迟的办法补上一部分。

### Q14：PushT 这么简单，在它上面比较三类世界模型，结论能推广吗？

能推广的是**方法**：用同一把尺子、同一组策略、同一套指标去比较，以及"怎么判断一个评估器可不可信"。
不能直接推广的是**名次**：哪一类模型在 PushT 上更好，取决于这个任务的特点（平面、单物体、接触简单、画面干净）。
换成有遮挡、有柔性物体、要长时程记忆的任务，排名可能不同。Phase 12 的毕业项目就是把这套方法搬到更难的任务上。

### 第 1 题

说出机器人学习和前面章节的游戏、仿真控制相比的三处主要不同，以及世界模型在每一处能起什么作用。

2. 策略：主流是模仿学习而不是强化学习。世界模型可以当策略的一部分（预测未来画面再解出动作），
   或者和动作联合建模。
3. 评估：每次评估都要上真机，慢、贵、难复现。世界模型可以当仿真器，在里面评估策略。

### 第 2 题

一个策略在真机上跑了 25 个回合，成功 20 次。成功率的标准误差是多少？95% 置信区间（正态近似）大约是多少？

<details><summary>参考答案</summary>

成功率 $20 / 25 = 0.8$。

$$
\mathrm{SE} = \sqrt{\frac{0.8 \times 0.2}{25}} = \sqrt{0.0064} = 0.08
$$

95% 区间的半宽是 $1.96 \times 0.08 = 0.157$，区间大约是 $[0.64, 0.96]$。

25 个回合测出的 80%，真实值在 64% 到 96% 之间都说得通。（成功率靠近 1 时正态近似偏差较大，更稳妥的做法是用 Wilson 区间。）

</details>

### 第 3 题

对同一个时刻要执行的动作，手上有两个预测：上一步预测的 0.2 和当前这一步预测的 0.6。
按 ACT 的时间集成（最早的预测 $i = 0$，权重 $e^{-m i}$），取 $m = 1$，求实际执行的动作。已知 $e^{-1} = 0.368$。

<details><summary>参考答案</summary>

上一步的预测更早，$i = 0$，权重 $1$；当前的预测 $i = 1$，权重 $0.368$。

$$
a = \frac{1 \times 0.2 + 0.368 \times 0.6}{1 + 0.368} = \frac{0.2 + 0.221}{1.368} = 0.308
$$

结果更靠近较早的预测。

</details>

### 第 4 题

某个观测下，演示里 25% 的人选动作 $-1$，75% 的人选动作 $+1$。用 MSE 训练的策略在这个观测上会输出什么？训练损失最低能降到多少？

<details><summary>参考答案</summary>

MSE 的最优解是条件均值：

$$
f^\star = 0.25 \times (-1) + 0.75 \times 1 = 0.5
$$

最低损失是条件方差：$\mathbb{E}[a^2] - (\mathbb{E}[a])^2 = 1 - 0.25 = 0.75$。

也可以直接算：$0.25 \times (-1 - 0.5)^2 + 0.75 \times (1 - 0.5)^2 = 0.5625 + 0.1875 = 0.75$。

输出 0.5 是一个没有任何演示者做过的动作。

</details>

### 第 5 题

行为克隆的策略在专家状态上每步出错的概率是 $\epsilon = 0.02$，回合长 $T = 20$。
按第 3.4 节的最坏情况分析，期望代价的上界是多少？如果出错后能立刻回到专家分布，期望代价是多少？

<details><summary>参考答案</summary>

最坏情况（出错后回不来）：

$$
\epsilon \, \frac{T(T+1)}{2} = 0.02 \times \frac{20 \times 21}{2} = 0.02 \times 210 = 4.2
$$

能立刻回来：$\epsilon T = 0.02 \times 20 = 0.4$。

两者相差约十倍，差别来自"错了之后停留在没见过的状态里"。

</details>

### 第 6 题

控制频率 30 Hz，动作块长度 $k = 20$，推理延迟 250 毫秒，异步执行。过期的动作有几步？执行长度 $T_a$ 可以取哪些值？

<details><summary>参考答案</summary>

一个控制周期约 33.3 毫秒。过期步数：

$$
d = \Big\lceil \frac{250}{33.3} \Big\rceil = \lceil 7.5 \rceil = 8
$$

可用步数 $k - d = 12$。可行条件 $d \le T_a \le k - d$，即 $T_a$ 取 8 到 12。

</details>

### 第 7 题

写出逆动力学 $p_\beta(a_t \mid o_t, o_{t+1})$ 与前向动力学、采集策略之间的关系，并说明在什么条件下它不依赖采集策略。

<details><summary>参考答案</summary>

$$
p_\beta(a_t \mid o_t, o_{t+1}) = \frac{p(o_{t+1} \mid o_t, a_t) \; \pi_\beta(a_t \mid o_t)}{\sum_{a'} p(o_{t+1} \mid o_t, a') \; \pi_\beta(a' \mid o_t)}
$$

即后验正比于似然（前向动力学）乘以先验（采集策略）。

当环境是确定性的、且不同的动作必然导致不同的下一观测时，对给定的 $(o_t, o_{t+1})$ 只有一个动作的似然不为零，
分子分母里的 $\pi_\beta$ 约掉，后验是集中在这个动作上的点分布，与采集策略无关
（前提是采集策略在该状态下做过这个动作）。

</details>

### 第 8 题

第 4.5 节的一维走廊，站在墙边 $x = 0$，观测到 $0 \to 0$。采集策略是（左 0.2，停 0.5，右 0.3）。
求逆动力学的后验。如果把动作编码成 $-1, 0, +1$ 用 MSE 训练，最优输出是多少？

<details><summary>参考答案</summary>

似然：左 1、停 1、右 0。似然乘先验：0.2、0.5、0，和为 0.7。

后验：左 $0.2 / 0.7 = 0.286$，停 $0.5 / 0.7 = 0.714$，右 0。

MSE 的最优输出是后验均值：$0.286 \times (-1) + 0.714 \times 0 = -0.286$。

</details>

### 第 9 题

逆动力学模型和 Phase 9 的隐动作模型有什么相同和不同？各说两点。

<details><summary>参考答案</summary>

相同：

1. 编码器的输入都是前后两帧，输出都是"这两帧之间的动作"。
2. 都受动作不可辨识的影响：两帧之间的变化如果不由动作唯一决定，输出就不可靠。

不同：

1. 监督信号：逆动力学模型用真实的动作标签；隐动作模型不用标签，靠"用隐动作重建下一帧 + 很窄的瓶颈"自监督。
2. 输出：逆动力学模型输出可以直接执行的真实动作；隐动作模型输出的是没有预定义含义的码，
   要再用少量带标签的数据映射到真实动作。

（另外：隐动作可以跨具身共用；隐动作会把与机器人无关的画面变化也编码进去。）

</details>

### 第 10 题

在 UWM 式的 World-Action Model 里，动作和未来观测各有一个扩散步 $j_a$、$j_o$。
写出"策略"和"前向动力学"两种查询各自的设置，并解释为什么把某个模态设成纯噪声等价于把它边缘化。

<details><summary>参考答案</summary>

- 策略 $p(A \mid o)$：观测的扩散步固定为 $J$（输入纯噪声），对动作从 $J$ 去噪到 0。
- 前向动力学 $p(O' \mid o, A)$：动作的扩散步固定为 0（输入给定的干净动作），对观测从 $J$ 去噪到 0。

纯噪声的输入与真实的变量独立，不携带关于它的任何信息。以一个独立的随机变量为条件，等于没有条件：
$p(O' \mid o, \tilde{A}) = p(O' \mid o)$。所以这时网络学到的就是边缘分布。

</details>

### 第 11 题

给定当前画面，动作与未来画面的联合分布是：

| | 块左移 | 块右移 |
| --- | --- | --- |
| 往左推 | 0.3 | 0.1 |
| 往右推 | 0.2 | 0.4 |

求：策略、视频预测、前向动力学 $P(\text{左移} \mid \text{左推})$、逆动力学 $P(\text{左推} \mid \text{左移})$。

<details><summary>参考答案</summary>

- 策略（行和）：$P(\text{左推}) = 0.4$，$P(\text{右推}) = 0.6$。
- 视频预测（列和）：$P(\text{左移}) = 0.5$，$P(\text{右移}) = 0.5$。
- 前向动力学：$P(\text{左移} \mid \text{左推}) = 0.3 / 0.4 = 0.75$。
- 逆动力学：$P(\text{左推} \mid \text{左移}) = 0.3 / 0.5 = 0.6$。

</details>

### 第 12 题

四个策略的真实成功率是 0.2、0.4、0.6、0.8，在某个世界模型里测得的成功率依次是 0.5、0.4、0.7、0.9。
计算 Pearson 相关系数、Spearman 秩相关和 MMRV。已知 $\sqrt{0.0295} = 0.1718$。

<details><summary>参考答案</summary>

**Pearson。** 真实值的平均 0.5，偏离量 $-0.3, -0.1, 0.1, 0.3$，平方和 $0.09 + 0.01 + 0.01 + 0.09 = 0.20$。

模型值的平均 $(0.5 + 0.4 + 0.7 + 0.9) / 4 = 0.625$，偏离量 $-0.125, -0.225, 0.075, 0.275$，
平方和 $0.015625 + 0.050625 + 0.005625 + 0.075625 = 0.1475$。

内积 $0.0375 + 0.0225 + 0.0075 + 0.0825 = 0.15$。

$$
\rho_{\mathrm{P}} = \frac{0.15}{\sqrt{0.20 \times 0.1475}} = \frac{0.15}{0.1718} = 0.873
$$

**Spearman。** 真实名次 1、2、3、4。模型里的名次：第二个策略（0.4）最低，记 1；第一个策略（0.5）记 2；其余是 3、4。
名次差 $-1, 1, 0, 0$，平方和 2。

$$
\rho_{\mathrm{S}} = 1 - \frac{6 \times 2}{4 \times 15} = 0.8
$$

**MMRV。** 只有前两个策略被排反，真实差距 0.2。每个策略的最大违例是 0.2、0.2、0、0。

$$
\mathrm{MMRV} = \frac{0.2 + 0.2 + 0 + 0}{4} = 0.1
$$

</details>

### 第 13 题

一个世界模型给出的成功率恰好是真实成功率的三分之一。它的 Pearson、Spearman、MMRV 各是多少？
它是一个好的评估器吗？为什么平均绝对误差不适合用来评价评估器？

<details><summary>参考答案</summary>

$\hat{y} = y / 3$ 是正的仿射变换，顺序不变。所以 Pearson 为 1，Spearman 为 1，MMRV 为 0。

它是一个好的评估器：用它做任何"哪个策略更好"的判断，结论都和真机一致。它只是不能用来报告成功率的绝对数值。

平均绝对误差衡量的是绝对数值的差距。它会给这个评估器打很差的分，
却会给一个"绝对数值接近、但把最好的两个策略排反"的评估器打很好的分。
评估器的用途是比较和选择，所以应该衡量排序的一致性。

</details>

### 第 14 题

世界模型每一步与真实环境的总变差距离不超过 0.001，回合长 200 步。
模型里的成功率与真实成功率最多相差多少？给出 $T \varepsilon_m$ 和更紧的 $1 - (1 - \varepsilon_m)^T$ 两个上界。已知 $0.999^{200} = 0.819$。

<details><summary>参考答案</summary>

$$
T \varepsilon_m = 200 \times 0.001 = 0.2, \qquad 1 - (1 - \varepsilon_m)^T = 1 - 0.819 = 0.181
$$

单步 99.9% 的一致，200 步之后成功率仍可能偏差 18 个百分点。这是最坏情况的上界，
实际偏差通常更小，但它说明了绝对数值为什么难以保证。

</details>

### 第 15 题

按第 7.3 节的模型：$\sigma^2 = 1$，真实样本 25 个，生成样本 100 个。
生成数据的偏差 $b = 0.3$ 时，混合训练比只用真实数据好吗？$b = 0.2$ 呢？

<details><summary>参考答案</summary>

判别条件：$b^2 < \sigma^2 (1/n_r + 1/n_g) = 1 \times (0.04 + 0.01) = 0.05$。

- $b = 0.3$：$b^2 = 0.09 > 0.05$，混合更差。
  验算：混合的均方误差 $(0.8 \times 0.3)^2 + 1/125 = 0.0576 + 0.008 = 0.0656$，只用真实数据是 $1/25 = 0.04$。
- $b = 0.2$：$b^2 = 0.04 < 0.05$，混合更好。
  验算：$(0.8 \times 0.2)^2 + 0.008 = 0.0256 + 0.008 = 0.0336 < 0.04$。

</details>

### 第 16 题

"模型被钻空子"在把世界模型当评估器时有哪三种形式？各举一个例子。

<details><summary>参考答案</summary>

1. **偏差与策略相关**（没有人在优化）：世界模型在演示数据附近准，在数据之外靠先验外推。
   例：训练数据多是成功的演示，模型对任何动作都倾向于画出成功，差的策略被高估。
2. **用评估结果做选择**：从很多检查点里挑模型里分数最高的。
   例：10 个真实水平相同的检查点，被选中的那个在模型里的分数会系统性偏高；而且模型的系统偏差不会因为多跑回合而消失。
3. **在评估器里训练**：把模型里的成功信号当作优化目标。
   例：在世界模型里做强化学习，策略学会了利用模型的物理错误，在模型里成功，在真实环境里失败。

</details>

### 第 17 题

DayDreamer 为什么要把采集数据和训练放在两个线程里？V-JEPA 2-AC 在真机上的用法与它有哪些根本的不同？

<details><summary>参考答案</summary>

机器人的控制周期是固定的，必须按时给出动作；而梯度更新的耗时不固定，也不需要和控制周期对齐。
分开之后，机器人不会因为训练而卡顿，训练也不受机器人节拍的限制：机器人每走一步，学习线程可以在想象里训练很多步。

V-JEPA 2-AC 的不同：

- 世界模型是离线训练好的（互联网视频预训练 + 别处采集的机器人数据），不在目标机器人上在线学习。
- 不训练策略，每一步用 CEM 在表征空间里规划。
- 任务由目标图像指定，不需要奖励。
- 不重建像素。

代价是每一步的计算量大，以及需要目标图像。

</details>

一篇假想的论文这样描述自己："我们在大量无标注的人类第一人称视频上训练了一个视频生成模型，
给定当前画面和文字指令，它生成未来 2 秒的画面；再用 50 条机器人演示训练一个小网络，从相邻两帧里输出机械臂的动作。

## 15. 小结与下章预告

### 15.1 本章要点

1. **机器人学习的现实。** 数据来自人的演示，没有奖励，量少而贵；主流是模仿学习；评估靠真机，
   20 个回合的成功率带着正负二十多个点的误差。
2. **模仿学习的两个毛病。** MSE 的最优解是条件均值，多峰时塌缩成一个没人做过的动作；
   分布偏移让误差随回合长度平方增长，和世界模型的复合误差同源。Diffusion Policy 对付前者，动作分块缓解后者。
3. **当策略。** 任何策略都可以拆成"下一帧的分布"乘以"逆动力学"。逆动力学是一个后验：
   $p(a \mid o, o') \propto p(o' \mid o, a)\,\pi_\beta(a \mid o)$。动作可辨识时它与采集策略无关，不可辨识时退回到先验。
4. **World-Action Model。** 把未来画面和动作的联合分布放进一个模型；策略、视频预测、前向动力学、逆动力学是同一张表的四种查询；
   用两个独立的噪声水平就能切换。
5. **当仿真器。** 模型里的成功率在绝对数值上难以保证（偏差上界随回合长度增长），要的是排序一致。
   用 Pearson、Spearman、MMRV 在一批已知真实结果的策略上验证，并配散点图。
6. **当数据引擎。** 有偏的生成数据在真实数据稀少时有用，条件是 $b^2 < \sigma^2 (1/n_r + 1/n_g)$；
   过滤和迭代都是在对模型的输出做选择，会富集模型的错误。
7. **真机。** DayDreamer 把"在想象中学习"搬上真机，靠异步的采集与训练；V-JEPA 2-AC 把"决策时规划"搬上真机，靠冻结的表征和 CEM。
   延迟、安全、奖励、重置是算法之外的硬约束。
8. **一条贯穿的警告。** 凡是对模型的输出做选择、过滤或优化的地方，都要问：模型的错误会不会被放大。

| 扩散策略 | Diffusion Policy | 用扩散模型生成动作块的策略 |
| 视觉-语言-动作模型 | Vision-Language-Action model (VLA) | 以视觉语言模型为骨干、输出机器人动作的模型 |
| 前向动力学 | forward dynamics | 给定当前观测和动作，预测下一观测 |
| 逆动力学模型 | Inverse Dynamics Model (IDM) | 给定前后两个观测，推断中间的动作 |
| 可辨识 | identifiable | 动作能从观测的变化里被唯一地确定 |
| 采集策略 | behavior policy / data-collection policy | 产生数据集里那些动作的策略 |
| 隐动作 | latent action | 从无标签视频里学出的、没有预定义含义的动作表示 |
| 伪标签 | pseudo-label | 由模型而不是人或传感器给出的标签 |
| 视频预测策略 | video prediction policy | 先预测未来画面、再据此得到动作的策略 |
| 世界-动作模型 | World-Action Model (WAM) | 把未来画面预测和动作生成放进同一个模型 |
| 神经仿真器 | neural simulator | 当仿真器用的学到的世界模型 |
| 策略评估 | policy evaluation | 测量一个策略的表现（本章指成功率，不是 Phase 4 的价值估计） |
| 成功率 | success rate | 成功的回合数除以总回合数 |
| 标准误差 | standard error | 估计量的标准差，衡量测量的统计误差 |
| 成功判定器 | success detector | 判断一个回合是否完成任务的规则或模型 |
| 皮尔逊相关系数 | Pearson correlation coefficient | 衡量两组数线性相关程度的指标 |
| 斯皮尔曼秩相关 | Spearman rank correlation | 对名次计算的相关系数，衡量排序的一致程度 |
| 平均最大排序违例 | Mean Maximum Rank Violation (MMRV) | 按真实差距加权的排序错误指标，越小越好 |
| 总变差距离 | total variation distance | 两个分布之间差别的一种度量 |
| 数据引擎 | data engine | 用模型生成训练数据的流水线 |
| 神经轨迹 | neural trajectory | 世界模型生成并打上伪动作标签的轨迹（DreamGen 的用语） |
| 模型被钻空子 | model exploitation | 对模型输出的优化或选择放大了模型的错误 |
| 仿真到真实的差距 | sim-to-real gap | 在仿真里有效的策略到真机上性能下降 |
| 域随机化 | domain randomization | 训练时随机扰动仿真参数，使策略对差异不敏感 |
| 系统辨识 | system identification | 用真实数据拟合仿真器或模型的参数 |
| 零样本 | zero-shot | 不在目标环境或任务上采集数据、不做训练，直接部署 |
| 目标图像 | goal image | 用一张"完成后的样子"的图像来指定任务 |
| 推理延迟 | inference latency | 从获得观测到给出动作所花的时间 |
| 异步执行 | asynchronous execution | 推理和动作执行同时进行，互不等待 |
