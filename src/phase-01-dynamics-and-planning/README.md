# Phase 1: 世界模型导论——动力学模型与模型预测控制

> **学习目标**：说清楚世界模型是什么；从数据里学一个动力学模型，并用它做规划来控制系统
> **预计时长**：2 周（第 1–2 周）
> **前置**：`deep-learning-course` 的 PyTorch 基础（MLP、训练循环）。不需要强化学习基础
> **状态**：README ✅ ｜ CONCEPT.md ✅ ｜ 讲义 8/8 ✅ ｜ 项目 ⏳

## 🧭 在课程中的位置

这是整门课的起点。本章故意选最简单的设定：状态是几个数字（角度、角速度），不是图像；
模型是一个小 MLP；决策靠"在模型里试很多条动作序列，挑最好的"，不需要任何强化学习理论。

在这个最简单的设定里，世界模型的全部核心问题都会出现：

- 模型怎么学（监督学习）
- 模型错了怎么办（复合误差、不确定性）
- 模型怎么用（规划）

后面的章节是把这里的每个部件换成更强的版本：状态换成从图像学到的隐状态（P2、P3），
规划换成在想象中训练的策略（P6），MLP 换成 Transformer 或扩散模型（P8、P9）。
本章写的 CEM / MPPI 规划器会一直用到 P3、P7、P10。

## 📚 本阶段内容

### 1. 世界模型与环境

- `01-what-is-a-world-model.py` - 手写摆的物理方程作为"完美世界模型"，演示预测、想象、规划
- `02-gymnasium-and-mdp.py` - Gymnasium 交互循环、MDP 的基本词汇、采集转移数据集

### 2. 学习动力学模型

- `03-learning-dynamics-mlp.py` - 用 MLP 预测状态变化量，输入输出归一化
- `04-compounding-error.py` - 开环多步展开、误差如何随步数增长、多步损失、分布偏移

### 3. 用模型做规划

- `05-random-shooting-mpc.py` - 把规划写成优化问题；随机打靶 + 滚动时域控制
- `06-cem-and-mppi.py` - 交叉熵方法（CEM）与 MPPI，同等算力下对比三种规划器

### 4. 不确定性与完整闭环

- `07-uncertainty-and-ensembles.py` - 偶然 / 认知不确定性、高斯 NLL、概率集成
- `08-pets.py` - PETS：概率集成 + 轨迹采样 + CEM-MPC + 迭代采集数据

## 🧠 核心概念

详见 [CONCEPT.md](./CONCEPT.md)《世界模型导论：从动力学模型到模型预测控制》：

1. 什么是世界模型
2. 世界模型的分类与全景
3. 用 MDP 描述智能体与环境

5. 多步预测与复合误差

## 🎯 实战项目

**机械臂模型预测控制**（`projects/phase-01-arm-mpc/`）：从交互数据学习 MuJoCo 二连杆机械臂
（`Reacher-v5`）的动力学，用概率集成 + CEM-MPC 控制末端到达目标点，
