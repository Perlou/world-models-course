# Phase 12: 研究工程方法与毕业项目

> **学习目标**：掌握把一个想法做成可信结果的工程方法（数据、训练、评估、消融、写作），并完成一个机器人世界模型方向的毕业项目
> **预计时长**：3 周（第 25–27 周）
> **前置**：Phase 1–11
> **状态**：README ✅ ｜ CONCEPT.md ✅ ｜ 讲义 0/4 ⏳ ｜ 项目 ⏳

## 🧭 在课程中的位置

前面十一章每章的项目都是"照着已知答案做"：环境选好了，方法定好了，预期结果也大致知道。
毕业项目不一样：题目要自己定，范围要自己控制，结果好不好要自己判断。

本章不讲新的模型，讲的是做研究型项目时反复用到的方法：

- 怎么选一个三周做得完的题目
- 怎么搭数据管线，让实验可复现
- 怎么把训练搬到云端 GPU，控制成本
- 怎么评估才算数（多少个种子、报告什么统计量）
- 怎么做消融，怎么把结果讲清楚

你有全栈工程背景，这是优势：一个能在浏览器里交互的演示、一个清楚的评估看板，
在这个方向的作品集里很有说服力。三个候选项目里有一个专门发挥这一点。

## 📚 本阶段内容

### 1. 数据与训练

- `01-offline-data-pipeline.py` - 离线数据管线：数据格式、切分、缓存、数据校验
- `02-scaling-up-training.py` - 把训练搬到云端 GPU：配置管理、断点续训、混合精度、成本估算

### 2. 评估与表达

- `03-evaluation-protocol.py` - 评估协议：随机种子、置信区间、IQM、世界模型的开环与闭环指标
- `04-ablations-and-writing.py` - 消融实验的设计；结果的整理与写作

## 🎯 实战项目

毕业项目三选一，在 Phase 11 结束时再定：

| 项目 | 做什么 | 特点 |
| --- | --- | --- |
| `capstone-dream-to-manipulate` | 多任务操作的世界模型 + 规划或想象训练，对比行为克隆和 Diffusion Policy | 最贴近"世界模型用于机器人控制"的主线 |
| `capstone-robot-world-simulator` | 机器人神经仿真器 + 策略评估看板 + 浏览器遥操作 | 发挥全栈优势，演示效果最直观 |
| `capstone-jepa-robot-planner` | 冻结的视频编码器 + 动作条件预测器，做零样本目标规划；可选低成本真机 | 最接近当前的研究前沿 |

## 💻 算力与环境

- 毕业项目需要租用 4090。具体时长取决于选题，开始前先用小规模实验估算，再定预算。
- 各候选项目的环境依赖（PushT、Meta-World、LIBERO、LeRobot 等）在选题后确定并写入项目自己的环境配置。
